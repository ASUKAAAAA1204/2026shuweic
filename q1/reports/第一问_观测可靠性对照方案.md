# 第一问观测可靠性预测：比较与优化方案

预测对象为已知当前源质量标记时，手别锚点后 (0, 0.2] 秒内至少一次被源标坏的概率。训练和开发使用既有质量锚点（逐手每六帧选锚），重新核对历史和未来标记均已知。当前正常时的阳性称“起始事件锚点”，可以包含复发。另评过去 0.2 秒全部未标坏的子集。自然遮挡的真实空间误差没有独立标签。

## 研究依据

- Guédon 的隐半马尔可夫模型显式描述状态持续时间。本题直接看得到质量状态，因此先检验“最近是否转换、已维持多久”有无超出二状态的收益。[Guédon 原文](https://www.tandfonline.com/doi/abs/10.1198/1061860032030)
- Saito 与 Rehmsmeier 研究不平衡样本中的精确率和召回率。以 Brier 衡量概率准确性，同时在同环境、同来源的正常锚点上用平均精确率 AP 和同预算报警衡量排序。[原文](https://doi.org/10.1371/journal.pone.0118432)
- 来稿《第一问多方案试验报告》比较过持续性、质量历史逻辑回归、运动特征、概率校准及两模式混合。质量历史逻辑回归相对持续性改善 2.62%，95% 区间跨零；两模式方法只在 11/16 外折满足准入。优先设置独立的历史与运动消融。用户提供的 VAE、GMM-HMM 和贝叶斯网络方案提出“状态和可靠性耦合”，本文用可见状态时长及运动增量做低成本检验，不能把这一比较外推为对完整视觉模型的验证。

## 组别与执行顺序

| 简称 | 训练规则 | 直接比较 |
|---|---|---|
| Constant、State、Source、LR | 复现已有训练发生率、加一平滑二状态、按来源收缩二状态（强度 50）、四特征逻辑回归（当前标记、历史坏帧占比、质心速度中位数及标准差） | 基础模型比较，同时核对逐锚点归档 |
| Q | 与 LR 相同的标准化 L2 逻辑回归，只保留当前标记和历史坏帧占比 | Q 对 LR 检验整体引入运动特征的差别 |
| D50、D | 按当前标记，再按过去 0.2 秒内是否见过相反标记分组。无相反标记单列；有时按本轮连续同状态的已观测时长小于 0.1 秒或至少 0.1 秒分组。分组率向本状态概率收缩，D50 固定 50，D 在 10、50、200 中由外折内部四个环境组选择 | D50 对 State 检验持续时间信息；D 对 D50 检验调收缩强度 |
| HQ、HM | 已标坏组沿用 D。当前正常组按等权混合 D 与只在正常锚点拟合的 L2 逻辑回归。HQ 的回归使用历史坏帧占比、是否近期转换及连续时长；HM 再加历史质心速度中位数、标准差、末速度和末两帧 21 点速度分散程度（到各点平均速度的距离中位数） | HQ 对 D 检验正常组单独建模；HM 对 HQ 只改变运动输入 |

所有可学习步骤均排除持出环境。每个外折内部按环境标识排序后轮流分四组，以三来源等权 Brier 选 D 的强度；并列先取 50、200、10。所有逻辑回归固定 C=1，以训练数据标准化，单类训练子集回退加一平滑频率。除已有对照以外，所有新增模型至多使用锚点前 0.2 秒和当前帧。球半径、未来运动、其他手真实未来、区间终点和视频后续均不作输入。

## 评估和判据

1. 先做 16 个官方训练环境的全局留一，同一环境的不同来源、左右手同进同出。再将相同配置在全部训练环境上拟合，以既有 4 个开发环境作一次同口径复核；该开发划分有既往使用史。测试集封存。
2. 主指标为逐记录平均、环境平均、来源等权的 Brier，越低越好。附报当前正常、当前已标坏、整段历史正常三个子集的 Brier 及计数。对当前正常和整段正常锚点，按环境和来源报 AP、事件率、风险最高 10% 的精确率与召回率，同分并列按比例分配。AP 仅在两类都存在的组中报告，警报预算用于比较排名。
3. 两个主要候选为 D 和 HM，对 State 计算整体相对 Brier 降幅和全局环境配对 bootstrap（5,000 次有效重抽，三来源须均存在），同时给出 95% 和 Bonferroni 97.5% 区间。建议替换需校正下限大于零且开发整体同向。其余比较为机制诊断。预警还需在当前正常尤其整段历史正常子集，对照各组事件率考察 AP 和同预算召回；总体改善不能单独支持提前预警。
4. 明确标记来源：EgoDemo 区分手别，EgoPro、EgoStandard 的全局坏标记可在左右手重复出现。按手别锚点计数，并列出按记录与帧索引合并后的阳性时刻数。Brier 的独立不确定性单位用环境。开发集不挑模型参数、阈值或特征。
