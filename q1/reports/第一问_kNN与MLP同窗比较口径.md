# kNN 与残差 MLP 的同窗、同折、同机比较

以既有 1,523 窗为清单，用全部 16 个官方训练环境做留一。B、K 和 K₀ 直接调用六组实验的推理入口，结果须逐点匹配归档。主比较为 K₀、K 分别对本地三维残差 MLP。模型名 M3。另作配对机制对照 M1，与 K 共用四个运动特征、训练来源、速度资格、回退基线、沿向输出和半幅修正。来稿 MLP 未提供源码及隐藏层等完整配置，两种本地模型均不能认定为原网络的精确复现。

M3 使用锚点相对的三维历史位置（−0.2、−0.1333、−0.0667 秒，历史内逐轴插值，端点夹取）、末速度与查询年龄，输出三维残差。M1 输入为末速度大小、前后两段速度大小、夹角和查询年龄，输出沿向残差。两者按来源拟合；M3 用全部同来源训练窗，M1 用 K 的合格训练窗。训练缺来源或 M1 库不足五个时回退 B。网络为一层 16 单元 tanh，Adam、学习率 0.003、L2 系数 0.01、最多 60 轮、批大小至多 256，固定完整 60 轮。每窗等数抽取六个从第一未来点到末端的实际采样点，历史输入按当前拟合数据标准化。训练标签为相对于 B 的参考残差，除以折内来源位移尺度及年龄系数 1−exp(−h/0.2)；预测时乘回两者，保证起点为锚点。M1 为匹配 K 再乘 0.5，M3 直接使用完整修正。在实际评价轨迹的全部采样时刻计分。

主种子 20261120，另用连续四个种子检查初始化敏感性。固定架构与学习预算，不用持出环境选网络或种子。同一进程、单 CPU 计算线程、批大小一窗、同时输出全部年龄点；预热、轮换执行顺序、每窗重复五次取中位，再报告窗口间中位和 P95。报告建库或拟合时间、模型占用（核心数值数组）与线上预测成本，分别解释。

复用官方训练归一尺度和逐层等权指标。全局环境配对 bootstrap 共用 5,000 个三来源齐全的有效样本。报告 K₀ 和 K 相对 M3 的提升及各自 95% 区间，并附两项比较的 97.5% 双侧区间；M1 作机制参照。使用原基线晋级标准时仍须比较 B；不能仅凭击败某个备选晋级。评估范围限于训练环境留一。
