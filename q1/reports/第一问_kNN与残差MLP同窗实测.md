# 第一问 kNN 与残差 MLP 同窗实测

**结论。** 在同一批训练持出环境中，两种 kNN 都优于本地三维残差 MLP。换成与完整历史 kNN 共用输入特征和修正方向的沿向 MLP 后，kNN 的精度优势消失，沿向 MLP 的推理也更快。若只能保留一个学习型备选并看重重复推理成本，本次更支持保留沿向 MLP；若希望追查每次预测所借用的历史样本，kNN 仍有用途。正式主模型继续使用固定阻尼。

## 比较范围

复用了上一轮的 1,523 个窗口、55 条训练记录和 16 个全局环境外折。窗口键、手别、起止索引、观测时刻、参考坐标、归一化尺度逐项核对。每次全局留出同一环境的全部来源记录，五种方法在同一来源与同一持出窗口上计分。B、K、K₀ 重新推理的所有坐标与原归档逐点一致。0.2、0.6、1.0 秒等权，逐级汇总、归一化和环境配对重采样沿用上一轮口径。

原报告的小型残差 MLP 缺少实现快照、完整超参数和权重。本次比较对象是事先写入实验口径的两种本地实现。来稿中的 0.387033 不参与排名。M3 使用锚点相对三维轨迹、末速度和预测年龄，直接预测三维阻尼残差；M1 与 K 使用相同的四个运动特征、同来源训练库资格、回退条件及半幅沿向修正，查询年龄用于预测对应时刻的误差。K₀ 只按末速度检索。M1 与 K 的差异主要是用神经网络或近邻检索估计残差；M3 与 M1 同时改变了输入、修正空间、数据资格和修正强度，无法用两者差值单独归因于某一项。[模型与计分口径](第一问_kNN与MLP同窗比较口径.md)

## 主种子的误差与开销

下表误差为归一化时间加权 ADE。时延为同一 Intel Core Ultra 9 275HX、同一 Python 进程、BLAS 单线程、批大小一窗的实测值。一次推理从内存中的质心历史和预测年龄开始，输出整窗所有坐标。每窗先预热，再按轮换顺序各测五次。P50、P95 基于各窗五次的中位数。两种 MLP 直接执行等价的 NumPy 稠密层，前向运算与 scikit-learn 输出另行核对。

| 方法 | 归一化 ADE ↓ | 相对阻尼改善 | 推理 P50 / P95（微秒） |
|---|---:|---:|---:|
| 固定阻尼 | 0.386521 | 基准 | 6.2 / 7.3 |
| 仅末速度 kNN | 0.377196 | +2.41% | 72.2 / 103.3 |
| 完整历史 kNN | 0.376263 | +2.65% | 76.6 / 110.9 |
| 三维残差 MLP | 0.452757 | -17.14% | 37.4 / 50.6 |
| 沿向残差 MLP | 0.375442 | +2.87% | 52.9 / 72.7 |

每个环境–来源实例的建库耗时中位数为 3.87 毫秒；沿向与三维 MLP 的拟合耗时中位数分别为 87.94、105.21 毫秒。

离线成本按主种子的 20 个“持出环境 × 评价来源”模型实例衡量。两种 kNN 共用一个库；核心数值缓存中位约 187 KiB。沿向 MLP 与三维 MLP 的前向参数及标准化数组分别占 984 和 2,408 字节。该口径排除 Python 对象、训练优化器、共同输入和输出内存。kNN 缓存统计含所引用的训练时间与残差数组。建库计时使用已缓存的可见特征；神经网络拟合计时包括训练特征和标签生成。逐实例耗时、大小均已保存。[计时明细](../results/q1_knn_mlp/timing.csv) · [建库与拟合开销](../results/q1_knn_mlp/fit.csv)

## 核验与复现

从保存的逐点三维预测及上一轮相同的参考坐标，用独立的分段积分重新计算 59,397 行指标，归一化 ADE 最大绝对差小于 3.2×10⁻¹⁵。B、K、K₀ 的主指标及已有 K/K₀ 对 B 的 95% 区间与上轮一致。重复运行后，全部种子的逐窗误差表哈希一致。仅用了官方训练环境，结论限于该折外比较。[积分复核](../results/q1_knn_mlp/score_audit.json) · [模型预测](../results/q1_knn_mlp/predictions.npz) · [运行环境及冻结输入哈希](../results/q1_knn_mlp/run.json)
