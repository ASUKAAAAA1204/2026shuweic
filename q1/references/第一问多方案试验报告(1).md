# 第一问多方案试验报告：训练内比较 v1

日期：2026-11-20。关联计划：[执行总计划](../../第一问多方案试验执行总计划_v1.md)。

## 1. 核心结论

本轮实际执行了55条训练记录、16个全局环境的环境分组嵌套比较：1533个位置预测窗口，15512个质量事件预测样本（248个正样本，非248个独立坏事件）。没有读取本轮开发验证轨迹，也没有读取测试轨迹或计算测试性能。

在本轮候选和口径内，没有新动态模型达到预注册的“至少3%改善且区间支持改善”的替换门槛。小型残差MLP及头部/双手上下文版本与固定0.2秒阻尼几乎持平；Kalman、软门控和IMM没有证明优势。不能把这一结果解释为所有Kalman、IMM、MLP或视觉方法都无效，也不能宣布阻尼是全局最优。

可靠性模型主要利用质量标记持续性；其相对质量持久性基线的改善较小且区间跨0。独立划分校准环境后仍存在明显欠覆盖，不确定性暂不具备可宣称的90%环境迁移保证。

**本轮交付的是可复查的训练内多方案比较，不是第一问最终定稿、测试验收或方法突破。**

## 2. 数据与评估核验

- 55条训练记录的110条手通道已与原始Parquet/CSV位置逐值核对，转换最大绝对误差为0，见[原始转换独立核验](../01_audit/independent_raw_conversion_check.csv)。
- 官方环境划分之间未发现同名环境交叉；发现3名操作者跨train/test出现，所以不能声称未来测试检验“未见操作者泛化”。精确全通道重复检查通过；尚未以近重复检索排尽部分片段复用。
- 非正时间差、非有限位置在训练审查中均为0。合格位置参考需要数值有效、源未标坏、质量已知、四元数范数合格与时间连续；不把源观测称为独立物理真值。
- Demo可确认索引0命名为腕点，但其拇指关节命名与新版官方MCAP文档不同。CSV字段与官方约定相符尚不足以确证导出版本；腕/掌/朝向分支继续受语义核验限制。本轮不使用未经确认的关节语义。
- CSV主质量标签沿用源全局标记，另完成明确left:/right:原因的手别敏感性；Demo采用原手别稀疏标记，未列出仅解释为未标坏。
- 最后可见时刻为t0，只以实际t-t0定义未来时长。时间加权ADE含t0锚点0误差；FDE为不超过指定时长的最后实测点，不伪造精确1秒位置。
- 主历史0.2秒、时长0.2/0.6/1秒、锚点至少间隔2秒。来源→环境→记录→手→窗口等权；尺度为当前训练折1秒位移范数中位数，缺来源时回退训练池尺度。
- 16个训练环境外层留一；内层最多4个环境组；预处理、噪声、专家、门控、早停、缩放均不使用外层环境目标。全局同环境跨来源一起留出。
- 独立重算41391条动态指标，最大ADE差异为1.1102230246251565e-16，低于1e-9门槛。见[计分核验](independent_score_check.json)。
- 在一个代表外折中，对全部动态模型族和五类可靠性预测器删除评价目标后重新预测；结果一致。见[信息隔离检查](../01_audit/predictor_information_isolation.json)。这是代表折代码路径检查，不冒充逐折形式化证明。

区间由全局环境成对bootstrap获得，共5000个有效重采样；缺失整来源的重采样被拒绝，拒绝数逐项记录。因此这是条件于各来源均被代表的区间，且不是多重比较同时置信区间。不报告未经校正的多重显著性结论。

实现范围：Kalman仅共享各轴协方差并输出锚定t0的速度外推；IMM采用静止/CV两模式、共享各轴协方差近似；MLP为自建小型残差网络，不是siMLPe完整复现，也不是USST复现。负结果只约束这些具体实现与参数范围。

### 3.1 消融和敏感性

- MLP五seed主指标范围0.386897–0.387431，既有略好于基准，也有略差；默认seed的微小优势不足以支持稳定提升。
- 形状摘要0.388368；上下文0.386400；形状＋上下文0.387708，均未达到3%改善门槛。新增上下文只使用不晚于t0的头/另一只手观测，不使用真实未来头部。
- 在1115个共同锚点上比较0.1/0.2/0.4秒历史：MLP分别0.420911/0.420460/0.421111，无稳定的“越长越好”。两点速度阻尼只用最后两点，因此三个历史长度结果相同，这是算法定义导致的预期不变性。
- 将最小锚点间隔增至3秒的原样本子集：MLP0.395353，固定阻尼0.396268，仍只有约0.23%差异。该子集不与全窗口绝对指标混比。
- 已保留原始任务描述和事后阶段分组，见[阶段汇总](../03_ablation/offline_phase_summary.csv)、[任务描述汇总](../03_ablation/task_description_summary.csv)。阶段计算使用任务终点，仅用于离线解释，未进入预测输入。任务描述细分稀疏，不能将来源、环境和任务混杂解释成因果。
- 失败案例按每来源最差3窗、MLP最大收益/最大退化各3窗和固定seed随机3窗选取，共36张图，见[索引](failure_case_index.csv)和failure_trajectories目录，未只选成功案例。

## 4. 观测可靠性

目标是未来0.2秒是否出现源标坏事件，不能等同于未来真实定位错误。训练来源中坏段按手通道计158段；CSV全局标签在两手重复，准入审查按记录去重后的事件计数，不能把158段当作158次独立物理故障。

|方案|来源等权Brier（低优）|相对质量持久性改善|环境配对95%区间|
|---|---:|---:|---|
|来源常数|0.01519092|退化|—|
|质量持久性|0.00841410|基准|—|
|逻辑回归|0.00827482|+1.655%|[-0.576%, +3.922%]|
|加性模型|0.00828132|+1.578%|[-1.696%, +3.500%]|
|浅树提升|0.00827773|+1.621%|[-0.488%, +5.404%]|
|逻辑回归＋校准|0.00827492|+1.654%|[-0.994%, +3.713%]|
|只用质量历史的逻辑回归|0.00819363|+2.620%|[-2.166%, +5.763%]|
|只用运动的逻辑回归|0.01477198|明显退化|—|

这说明“超过常数模型”的相当部分来自质量标签持续性。不能只与弱常数基线比较后宣称运动特征具有强可靠性预测价值。

手别标签敏感性：Brier为手别逻辑回归0.00569422、手别持久性0.00569302，二者几乎相同；标签口径会改变事件率和绝对Brier。两模式可靠性混合仅11/16外折满足所有内部事件准入规则，匹配子集Brier：混合0.00476957、逻辑回归0.00480249、持久性0.00486349；这是条件子集结果，不能混入16环境全量排名，也未证明增益稳定。

已输出ROC-AUC、平均精确率、事件率、分源校准表及误报/漏报案例。单类组不填造AUC。按来源汇总的折外AUC可能受到跨折训练先验变化影响，不解释为单环境内判别能力。

## 5. 空间误差风险与误差范围

### 5.1 独立空间误差风险

另建目标：固定阻尼在最后可用<=1秒参考点的FDE是否超过训练尺度的2%/5%/10%，不与源质量事件混用。主5%容差下，常数Brier0.03330364，逻辑回归0.02861083，约改善14.1%；这是辅助训练内结果，尚未完成环境配对区间和开发验证，不作为正式获胜证据。

该事件发生率按来源约93.7%–98.8%，极度偏向“会超差”，因此接近1的PR指标不能直接说明模型很强。容差过严和点预测精度不足都需要进一步论证，不能据此采购频繁观测。

### 5.2 两套范围试验不能混淆

第一套：在每个外层训练内部重新生成折外残差，以全部可用训练环境校准分时长/条件分箱半径。固定阻尼、1秒范围内逐点覆盖：Demo87.39%、Pro88.23%、Standard91.27%；条件分箱未稳定改善。这里的“1秒”指整个1秒范围内帧覆盖平均，并非仅终点覆盖。

第二套：进一步把外层训练环境分成拟合组和独立校准组，在相同分区比较：U0分时长半径、U1条件尺度后校准、U2线性分位数回归后校准。固定点预测不需要拟合，避免校准标签进入点模型训练。结果如下（1秒范围内逐点覆盖/平均半径）：

|方法|Demo|Pro|Standard|
|---|---|---|---|
|U0|87.27% / 0.16115|77.35% / 0.13862|73.01% / 0.16632|
|U1|87.68% / 0.16101|88.32% / 0.16204|76.80% / 0.16922|
|U2|88.84% / 0.17370|84.41% / 0.14549|81.74% / 0.18243|

半径保留源单位，不能无核验地改写成厘米。U1/U2部分收益伴随半径增加，且分来源存在权衡。校准组有时缺Pro来源，只能回退到训练尺度归一化后的池化校准，详见uncertainty_split_partitions.csv。这是少环境校准代表性不足的直接风险，不能靠总体平均隐藏。

逐点90%不等于整段90%；两套试验均单独保存整段同时覆盖，明显更低。依赖帧与环境迁移下，不宣称经典独立可交换样本的覆盖保证。当前不冻结“可靠90%预测球”。

## 7. 工程修复与偏离说明

- 首次试运行内层按折等权汇总，随后修正为明确来源—环境—记录—手权重并全量重算；初稿保存在02_oof/preliminary_fold_average，不混入最终结果。
- 深层折可能缺少Pro，补充训练池尺度回退。未借用留出来源目标尺度。
- 原MLP特征函数在预测时顺带构造随后丢弃的目标数组；已拆为targets=False的无目标路径，并验证输出与已存折外预测一致。这不是已发现的数值结果依赖未来目标，但该不必要读取不符合严格预测接口，现已修复。
- 独立校准的U2集中在没有拟合参数的固定点模型上，未给所有MLP变体重复拟合U2；这属于范围限定，不写成全组合均已比较。
- PDF绘图后端依赖不可用，改为PNG轨迹；数值结果不受影响。报告导出中语法/导入错误修正后重跑并核对输出，不能把首次失败当作模型失败。
- 本轮为论文机制的小型实现试验，未声称完整复现USST/siMLPe。原题同状态要求通过共同21点中心目标保持，状态扩展只增加历史输入，未凭更平滑目标降低误差。
