# 失分、信息限制与失败试验

## 失分分解

从360次训练环境组标称回放重新抽样并归属来源，覆盖4320个任务实例。来源身份仅在回放结束后用于评估，不进入策略。按来源环境分解不是环境因果效应，任务混合和任务族也不同，不能据此断言某环境导致失分。

|方法/任务族|截尾失分权重|迟到失分权重|其他未执行失分权重|前驱未完成失分权重|
|---|---:|---:|---:|---:|
|density A|11|88|56|0|
|新方案 A|11|100|50|0|
|density L|77|334|62|106|
|新方案 L|71|277|132|65|
|density P|21|91|88|28|
|新方案 P|22|67|112|8|

新方案减少L/P族迟到和前驱阻塞，但增加部分未执行任务，故按时率改善不能解释为整个任务链全部更好。原始逐任务表、分环境表、分族表见results/training_evidence/source_loss。

## 定向失败试验

1. 4500次训练回放：先验收缩、零收益恢复及组合没有稳定替代冻结方案的证据。
2. 3600次训练回放：双目标动作保护在模型内预测不损害完成率，留出表现却仍会退化；448个逐场景独立回放与向量化结果完全一致，说明不能靠忽略分布失配而宣称保护有效。
3. 246条区间、16环境留一：23个免费前缀特征的固定邻居条件分布，CRPS为6.2187，劣于族分布6.1484；MAE为7.4024，劣于7.1512。未通过预设门槛，没有进入验证。它只能否定这项固定方法，不能证明全部前缀信息无效。
4. 完成率约束的6例离线诊断全部找到更高按时率且不降低完成率的方案，4例已证最优。因此不能说完成率下降是必然代价；同时不能把已知未来时长的离线收益冒充在线可实现收益。

采用决定维持验证前冻结的候选，没有把后续试验中局部最好的单元拼成最终成绩。所有研究实现保留于相邻第三问优化目录。
