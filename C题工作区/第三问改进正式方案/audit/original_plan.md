# 第三问质量提升计划

## 目标与证据边界

在官方信息边界、预算、前驱与释放约束下，提高加权按时率，并给出可解释、有机制依据的创新。现方案作为冻结对照，不覆盖其结果。创新不能仅靠改名；须提出明确机制、消融与反例。不能承诺未知数据上的提升。

旧验证已多次查看，后续结果只称既有验证回放。官方最终测试种子缺失，保持测试性能封存。新随机种子仅增加蒙特卡洛精度，不构成新环境或独立泛化证据。

## 顺序与阶段门槛

1. **损失诊断与最优差距**：从冻结逐动作日志分解迟到、未执行、前驱阻塞、截尾及长尾影响；按场景、任务族、环境报告。实现小规模确定时长精确求解，核验8任务实例，再扩展12/16任务；求解超时同时报告可行解和上界。真实未来时长的离线解仅作诊断上界，绝不作为在线策略输入。分别比较已知时长最优、训练中位数计划和现有策略，区分信息损失与决策损失。
2. **结构化改进**：优先研究“前驱闭包＋截止可行性＋空间切换”的滚动任务集合规划。以完整任务链和待释放任务为规划对象，允许主动等待及舍弃已无价值的任务；执行一步后用真实返回重新规划。先做确定时长版本，检验是否克服局部密度排序缺陷。
3. **不确定性改进**：在第2步基础上引入仅由训练数据构建的时长场景，通过共同随机数比较滚动计划的期望按时收益及尾部失败。每个决策使用相同场景比较动作；不得读取实际抽样索引或未来时长。场景样本数只作计算收敛检查，不按旧验证成绩调参。
4. **有条件观测**：只有证据显示前缀能改变接近最优的选择且收益超过1秒与1成本，才研究决策价值复查；不得因需要创新而强行购买信息。没有证据则维持不复查，明确原因。
5. **冻结与验收**：训练环境留一筛选，缺族环境采用有声明的族条件诊断，不能静默补成真实联合环境。最多保留一个确定计划和一个随机计划进入统一回放。报告五映射、三场景、全部公共指标、配对差异及计算时间。

## 量化验收

- 目标：标称三场景等权加权按时率相对冻结对照提高至少3个百分点；逐场景退化不超过1个百分点。此为研究目标，未达到不能宣称完成高优率目标。
- 统计：报告同源同种子配对95%区间；按环境汇总，只有2个完整训练环境时不宣称有充分跨环境显著性。
- 最优差距：小规模精确结果与独立枚举一致；大规模提供求解界和时间限制。不能把中位数模型的最优解称为随机实际问题最优。
- 工程：非法动作0、独立计分误差不超过1e-9、未来隐藏载荷扰动不改变当前决策；报告每决策及每实例耗时分位数。
- 创新：对前驱闭包、空间成本、随机场景至少分别消融，说明收益来源和不适用条件。
- 交付：完整中文解答、模型公式、伪代码、训练与验证结果、消融、失败清单、逐动作日志、可复现代码和冻结配置。

## 防止无效重复

每次试验必须对应一个可检验的失败机制；先写假设和通过门槛再运行。没有进展时检查目标函数、搜索质量和时长信息上限，不能用增大网格代替诊断。阶段结果保留，包括失败结果；旧方案继续可用，但不得用“保留旧方案”冒充本轮高质量优化目标已实现。
