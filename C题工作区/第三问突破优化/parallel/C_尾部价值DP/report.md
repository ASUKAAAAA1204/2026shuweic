# 角色 C：尾部价值函数（受限 DP + 分布精确 MC 评论器）

**交接摘要（150 字）**
我用「受限时间桶 DP + 蒙特卡洛计划评估」替换 v2_s20 的密度贪心尾部。DP 在固定拓扑序上做带前驱约束的 0/1 背包，收益用全族分布积分；再用共享随机数的 MC 对「9 条 DP 计划 + 4 条 v2 贪心计划」统一估值，取最优计划的首个可执行任务。标称加权按时率 91.088%（基线 85.093%，v2 90.162%），五映射 88.764%，配对 95% 区间 [+4.537, +7.327]pp，27/30 种子为正，环境留出 +2.179pp。门槛四条全部满足；但对 v2 的 +0.93pp 区间含 0，且候选是在同一验证种子上选的，故不宣称对 v2 显著更优。

---

## 1. 假设

- H1：v2 的尾部评论器是 `w·P(按时)/(D+0.5+mean p)` 的**贪心指数**，它按单任务密度排序，看不见「为一条链预留时间」「用一个便宜任务换取后面两个高权重任务」这类组合取舍。用期望按时权重的**背包式**估值应当更准。
- H2：用**标量时钟**推进时间的 DP 会低估尾部（重尾：P 族 mean 7.49 / median 4.0 / max 125），所以必须对时钟场景做分位积分，而不是只用均值。
- H3：计划之间只在「第一个执行哪个任务」上有决策意义，因此**整条计划的期望按时权重**可以作为第一动作的价值函数；只要评估器无偏，排序就无偏。

## 2. 方法

### 2.1 受限 DP（`dp_table` / `extract_plan`）
- 状态：`(时间桶 b, 区域 z, 前驱未完成位掩码 m)`。按固定拓扑序逐个任务处理，`跳过` 或 `服务` 二选一。
- 服务：`start = max(t_b + D + 0.5, release)`，**完成 = start + clock[f]**（不重复计入移动/准备，符合 P1）；收益 `w·P(p_f ≤ min(due,H) − start)`，概率取自**完整分布**，不是中位数、不是均值。
- 预算：选取前先按费用筛掉不可负担任务，然后**继续**看下一个任务，不终止尾部（符合 P2）。
- 离散近似：分布固定 128 点分位网格；桶取 `ceil(end/dt)`，比真实完成时刻晚，因此对同一计划是**保守**（偏低）估值。
- 时钟场景：`timeline='mean'` 单场景；`timeline='quantile'` 取 q=0.2/0.5/0.8 三个分位，逐场景求计划并平均。

### 2.2 分布精确的 MC 评论器（`mc_eval`）
对整条计划抽 K 组时长（共享随机数 CRN，全计划共用同一批样本），每组样本独立回放：任务只有在其前驱**在该样本中真的完成**时才可服务 → 链式概率精确，并行分支互不惩罚（符合 P1 链式要求）；费用不足则跳过而非终止；完成 `start + p` 超过 H 则不计。返回 K 个样本的平均按时权重。

### 2.3 计划组合（`mode='mc'`，提交方法 `dp_mc_t4_s256_dt10`）
每次决策生成候选计划：3 个拓扑序（EDF / WDD / slack）× 3 个时钟场景 = 9 条 DP 计划；再用 v2 的一步评分取 top-4 候选，各生成一条祖先链门控的密度贪心尾部计划。全部用同一批 MC 样本估值，选价值最高计划里**第一个可执行**的任务执行（预留 0.2 s；不可执行则看下一条计划）。

### 2.4 降维与误差界
精确子集 DP 需 `2^n × 桶 × 区域 × 预算`，S3 约 1.7×10¹⁰ 状态，不可行。本实现的降维是**把子集维度换成固定拓扑序 × 链位掩码**：每步状态 `nb × nz × 2^b`（S3：129×5×8 = 5,160，dt=1.0）。由此：
- 策略类被限制在「按拓扑序选取」，只会降低可达到的价值 ⇒ DP 值是受限类最优的**下界**，不是全局最优；
- 桶向上取整 ⇒ 同一计划的时间推进偏保守，误差上界为 `n·dt`（S3：16 s @ dt=1.0）；
- MC 估计的标准误 ≤ `W_max/(2√K)`（权重上界 W_max，K=256 ⇒ ≤ W_max/32），且 CRN 使计划间比较是配对的。

## 4. 消融

**(a) 均值 → 分位积分**（plan 模式的纯 DP，标称 30 种子）

| 时钟 | dt=0.5 | dt=1.0 |
|---|---|---|
| 均值单场景 | 87.037% | 87.951% |
| 分位积分 q=.2/.5/.8 | 89.352% | 89.526% |
| 差值 | **+2.31 pp** | **+1.58 pp** |

结论：重尾下用均值时钟会系统性砍掉尾部任务，分位积分是纯 DP 可用性的前提（H2 成立）。

**(b) 密度 → DP**（K=256，dt=1.0，标称）

| 计划来源 | 标称 | 五映射 |
|---|---|---|
| v2_s20（密度贪心，指数排序） | 90.162% | 87.456% |
| 只用 v2 贪心计划 + MC 排序（`dp_mcg`） | 89.398% | 87.472% |
| 只用 DP 计划 + MC 排序（`dp_mcd`） | 88.669% | 86.947% |
| DP + 贪心计划，统一 MC 排序（提交） | **91.088%** | **88.764%** |

结论要如实说：**单独换成 DP 计划或单独换成 MC 排序都会变差**；收益只在二者组合时出现。也就是说 DP 不是更好的「贪心指数」，而是提供了贪心给不出的整条子集分配，MC 则负责在同一分布下比较它们。

**(c) 桶粒度 0.5 s vs 1.0 s**（提交组合，K=256）

| dt | 标称 | 五映射 | 每决策耗时（全样本均值） | S3 单次决策微基准 | S3 状态数 |
|---|---|---|---|---|---|
| 0.5 | 90.845% | 88.667% | 31.0 ms | 81.1 ms | 10,120 |
| 1.0 | **91.088%** | **88.764%** | 25.9 ms | 62.9 ms | 5,160 |

粗粒度反而略好（+0.24 pp）且快约 20%：桶向上取整的保守偏差与更多可负担组合之间的折中；差异量级（~1–2 个计分格）接近噪声，不作为结论。

**(d) MC 样本数 K**：dt=0.5 时 K=64/128/256 → 90.567/90.232/90.845；dt=1.0 时 K=256/512 → 91.088/91.042。K≥256 后趋于平台，说明 K=64 的计划排序有可观测的赢家诅咒。

| 方法 | 两折均值 | 折 0 | 折 1 |
|---|---|---|---|
| v2_s20 | +0.642 pp | −1.667 pp | +2.951 pp |

均值门槛（≥0）满足，且比 v2 的留出增益更稳；但**折 0 仍为负**，不能把单组结果当泛化证据。

## 6. 失败分析

1. **纯 DP 选首任务（`plan` 模式）打不过 v2**：30 种子下 89.35%（dt=0.5）/89.53%（dt=1.0），低于 90.16%。原因是 DP 的「拓扑序 + 标量时钟」把计划限制得太死，提取策略时又只取首个任务，计划价值与「首任务后重新规划」的真实价值不一致。
2. **`plan` + move-to-front 修复反而降分**（早期 15 种子开启 `repair` 时 87.64%，关闭后同协议 30 种子 89.35–89.53%）：`eval_plan`（确定性时钟 + 门控乘法）作为判别器有偏，逐计划平均 3 个时钟场景会把「高方差计划」估得偏高。这正是改用 MC 的动机。
3. **强制首任务 + DP 尾（`mc2`）显著更差**：修复前 88.5%，修复后（前缀不参与自身后继掩码）90.36%，仍低于 91.09%。诊断：多出来的计划与已有计划首任务相同却被 MC 分数拉开，说明「整条计划价值」在计划集合变大时放大了选择噪声；也说明 DP 尾部本身弱于贪心尾部，只有作为**额外**候选才有价值。
4. **S3 是瓶颈**：提交方法 83.96% vs v2 83.54%，仅 +0.42 pp。S3 有 3 条链、H=125、16 个任务，桶粒度与链掩码的联合近似误差最大；进一步收益应来自对 S3 的更细状态（预算入状态、按链分解）而非继续调 K。
5. **K=64 的假象**：早期 15 种子下 K=64 已到 90.81%，30 种子回落到 90.57%；说明小样本排序会制造乐观偏差，最终统一用 K=256。

## 7. 局限

- **选择偏差**：提交配置是从同一批 30 个验证种子上挑的（全部候选见 `results/summary.json` 的 `candidates.rows`）。91.088% 是**带选择偏差的点估计**；后修组合型候选落在 90.14–91.09%，两个种子半区为 91.18 / 91.00，可作为偏差幅度的粗略界，但不构成无偏估计。
- **对 v2 的优势未定**：配对区间 [−0.139, +1.956] 含 0；五种映射中 (1,1) 一档 88.553% 略低于 v2 的 88.646%。因此只能表述为「达到了任务书对基线的 6% 相对目标」，不能表述为「显著优于当前最好方法」。
- **未读 test**，全部数字来自 `results/trials.csv`；不引用任何未自行复算的上界（含 93.77% 完美信息上界——它与 S1=98.96 矛盾，本报告不使用）。
- **预算是经验上非紧**：S3 观测最大成本 35.58 < 40，故 cost 未进 DP 状态；若换预算更紧的环境，无法负担性只能在逐步筛与 MC 的 skip 语义里体现，会高估计划价值。
- **MC 与网格**：128 点分位网格是离散近似（不宣称精确保留混合权重）；MC 价值是 K 样本估计，K=256 的排序噪声仍可能导致个别决策翻转。
- **环境留出折 0 为负**（−0.59 pp）：验证集口径的提升不等于跨环境泛化。
