# 第三问：风险积分前瞻调度（验证集突破与留出结论）

## 一、结论摘要

新增一个决策算法 **lookahead（风险积分一步前瞻 + 贪心期望尾部估值）**，在官方验证集上相对 `pressure_gated` 基线：

| 指标 | 基线 | lookahead | 变化 |
|---|---:|---:|---:|
| 标称三场景平均加权按时率 | 85.09% | **90.80%** | **+5.71 个百分点 / +6.71% 相对** |
| S1 | 93.33% | 98.96% | +5.63 pp |
| S2 | 80.69% | 89.17% | +8.47 pp |
| S3 | 81.25% | 84.27% | +3.02 pp |
| 五种映射平均 | 83.82% | 87.52% | +3.70 pp |
| 加权完成率 | 94.07% | 95.00% | +0.93 pp |
| 平均成本 | 25.381 | 25.321 | −0.060 |
| 付费观测 | 0 | 0 | 0 |

- 配对（同场景、同种子、同映射）标称差值 95% 区间 **[+4.26, +6.99] pp**，26/30 种子为正。
- 五种时长映射（α=1/0.75/1.5，β=0/0.5/1）**逐一优于基线**，α=1.5 也不再退化。
- 独立计分与引擎计分最大差 **1.14×10⁻¹³**，所有动作通过释放、前驱、预算、时域、费用与预留校验。
- 未读取测试集；验证集只用于按题面规定的“在验证集选择模型”，未参与时长拟合。

**因此，在官方验证集这一指定选择口径上，6% 相对提升目标已达成。** 但见第四节：该增益在独立环境留出压力测试下并不稳健，不能据此宣称跨环境泛化。

## 二、方法

原基线的一步密度索引为 `w·P(按时)/(D+0.5+中位时长)`，存在两个结构性问题：把未来完全压成点估计；不评估“先做 j 会怎样挤占其余任务”。

lookahead 改为对每个可选任务评估**整段剩余时间轴**：

```
score(j) = w_j · P(j 按时) + E_tail(先做 j 之后)
```

- `E_tail`：在当前时长信念下，对剩余任务做贪心期望时长推演，累加“该推演会按时完成”的权重。
- `E_tail` 的期望对 j 自身时长**按 5 个分位点积分**，长工期会真实地压缩后继价值，而不是被均值抹平。
- 时长信念：族经验分布 → 按样本量向全局先验收缩（strength=40）→ 用实例内已完成工期收缩更新（feedback_strength=3）；全部在固定 128 点分位网格上表示，保证混合权重精确保留。
- 服务时间在每次生存判定前先做公开载荷映射 `p = α·d + β`（观测里公开给出 α、β）。
- 预留固定 0.2 秒：预留不改变完成时刻，只推后下次可用，故最小预留对按时率与成本同时最优。

文件：`code/lookahead_policy.py`。

## 三、验证集消融（标称三场景平均）

| 配置 | 平均 |
|---|---:|
| lookahead 完整（nq=5, s=40, fb=3） | **90.80%** |
| 去掉分位积分（nq=1，单中位点） | 87.28% |
| 去掉实例内反馈（fb=0） | 89.47% |
| 去掉全局先验（strength=0） | 90.43% |
| 基线 pressure_gated | 85.09% |

分位积分贡献最大；反馈与全局先验各自都有正贡献。三者同时存在才到 90.80%。

## 四、独立环境留出（重要警示）

将 16 个训练环境分成两组，交替做“一半拟合、另一半评估”，新种子、标称映射：

| 方法 | 组0 | 组1 | 平均 |
|---|---:|---:|---:|
| lookahead | 64.91% | 92.08% | 78.50% |
| pressure_gated | 68.42% | 88.37% | 78.39% |
| robust20_feedback3 | 69.93% | 89.88% | 79.90% |

配对比基线：lookahead **+0.10 pp**（组0 −3.51，组1 +3.72），robust20 **+1.51 pp**。

解读：lookahead 的大幅增益**依赖验证集所处的环境分布**；在“拟合一包环境、评估另一包环境”的强分布偏移下增益消失，而 robust20 仍为正。因此：

- 90.80% 是**验证集选择口径**下的真实、可复现结果，不是跨环境泛化证明。
- 该留出协议本身偏严苛（拟合池排除整段分布模态），但它足以说明增益对环境敏感。

## 五、6% 是否达成的准确表述

- **是**：在题面规定的验证集上，标称加权按时率 85.09% → 90.80%，相对 **+6.71%**，区间下界 +4.26 pp。
- **否（作为泛化保证）**：在独立环境留出上增益约 0，不能承诺测试环境同样提升 6%。

## 六、局限与选择偏差

- 验证集只有 S1/S2/S3 三个案例，标称平均的案例级方差大；区间按种子重采样，**不覆盖“在验证集上挑强度参数”带来的选择偏差**。
- `strength` 在 {20, 40, 60} 中取 40（对应标称 89.80 / 90.80 / 89.94），峰值较窄，存在噪声成分；机制本身（前瞻 + 分位积分 + 反馈）在整段参数区间为正。
- 环境留出显示增益不跨环境稳健，故 90.80% 只能作为验证集口径结论。

## 七、采用建议

1. 论文/汇报可写：验证集上相对基线提升 6.7%（+5.71 pp），并同时给出环境留出中性结果与验证集 ≤3 个案例的小样本限制。
2. 若最终提交以验证集指标为准且允许在验证集选择模型，可采用 lookahead。
3. 若更看重跨环境稳健，保留 robust20_feedback3（验证集 +0.93 pp，留出 +1.51 pp）作为保守方案，或把两者作为“激进/稳健”双候选同时报告。
4. 不把 lookahead 的 90.80% 表述为全局最优或已证明泛化。
