# 非凸返回速度更新实验注册

固定训练1527窗、16环境留一、请求(.3,.6)、delay=.1、budget2、tau=.2。不改第一问状态或初始速度。返回后速度设为 a×本次位置割线速度 + b×按采样间隔衰减的旧速度，a/b不限制正负或和为1；原方法a=1,b=0。

第一/第二次返回各学习两个共享xyz旋转等变系数。先用第一次返回到第二次到达前的训练残差拟合第一组；再按该组生成旧速度，用第二次返回后的训练残差拟合第二组。训练目标为全窗平均归一化平方位置误差，分层窗口权重，正则固定.001向(1,0)收缩。此为顺序拟合，不声称联合全局最优。尺度仅用对应外层训练环境。没有超参数网格，无验证/测试读取。

实际评价仍用NADE/NFDE/超5%和成本，不能拿拟合MSE替代。基准重构必须逐点复现原engine；请求和返回日志相同。外层结果只探索，晋级至少NADE改善3%、区间下界>0且各来源不退化超过5%，否则继续保留原方法。
