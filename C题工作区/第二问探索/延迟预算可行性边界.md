# 延迟与预算的经验可行性边界

仅训练1527窗、16全局环境。固定阻尼和割线更新不变；1秒人工遮罩；请求均匀分布在 k/(B+1) 秒，B=0..8；每次成本1、单挂起。没有修改正式两次预算协议，扩展预算仅作敏感性分析；开发/最终测试读取0。

若将5%容差目标明确为“来源等权平均至少90%计分时刻在容差内”，当前均匀网格结果：

- 零延迟：预算5次超差12.56%，6次7.998%，故已测网格首次达标为6次；这不是所有策略的理论最小请求数，也不保证每来源/每环境达标。
- 0.1秒延迟：预算8次实际平均7.41次，超差30.74%，仍未达标。
- 0.2秒延迟：预算8次实际平均3.83次，超差54.06%；单挂起和返回时间限制使名义预算并不等于能用完的有效观测。

这些结果说明“简单增加两次预算”不足以解决当前延迟下的严格容差。零延迟可通过更高观测量在经验平均上达标，提供一个充分场景，而非物理安全证明。保持0.1秒延迟时仍需研究更好的状态更新或重新明确可行容差；不能从有限网格推出数学不可能性。

数据与实现：results/resource_curve_8/summary.csv、all_windows.csv.gz、run.log；code/resource_curve_8.py。所有结果须标记为后续训练探索，不以其重选已看过最终测试的模型。
