# 内层独立选择校准规则注册

仅比较pooled校准的all_age、neighbor、prior_only三规则。每个外层排除后，将15个环境固定分成7拟合、4校准、4选择；随机种子20261121，仅按来源覆盖搜索首个可行分组，不看数值误差。三个组都须包含全部来源。Pro训练仅3环境，持出Pro后剩2，无法分成三份，必须记为选择不支持并保持all_age，不能删掉这些外层窗口或借外层补样本。

模型系数及尺度仅用拟合组，校准残差只用校准组，规则分位损失排名只用选择组，同误差下按all_age、prior_only、neighbor优先。固定距离候选及20步拟合。选择后从已有双层外层结果中取对应规则，评价全部1527窗。该内层选择方案是在多轮研究后提出，不产生新独立测试保证。7环境模型到15环境模型存在迁移差异，需公开。
