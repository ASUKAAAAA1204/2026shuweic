# 初始速度历史候选登记

本轮仅使用训练集固定窗口，检验此前只用两帧初始化是否漏用可见历史。候选固定为两帧差分基线、零初速、六帧端点割线、六帧带截距最小二乘直线斜率。后三者只改变初始速度；初始位置仍为最新可见位置，阻尼tau=.2，付费返回仍为原割线，固定(.3,.6)两请求/.1秒延迟。六帧候选要求六帧历史均reference_candidate且时间连续、间隔不超过.1秒，否则回退原两帧；不跨无效帧取位置、不读取窗口内轨迹来初始化。

不训练参数、不扩大网格、不访问验证/测试。所有窗口均保留，报告全窗及首次返回前NADE、NFDE、超5%率与可用历史比例，按原层级等权。参考资格含质量未知时的既有规则，结论限于现有离线重放；不自动把质量资格解释成独立真值。该试验不预设任何候选更优，也不修改第一问正式模型。

核验要求：两帧候选复现既有训练基线；首次返回起所有预测严格一致；历史使用索引全部小于缺失窗口起点；长历史无支持时与基线一致；保存逐窗结果供独立汇总。本轮只是机制筛查，若出现收益仍需匹配校准和更强独立证据。
