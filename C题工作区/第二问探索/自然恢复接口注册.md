# 自然恢复接口对比注册

仅训练55条记录。将源bad连续段作为事件候选，不等同纯遮挡；起点前需最近两帧合格且时间连续。恢复后分别评0.2/0.6/1秒，参考段必须连续合格、时长完整；排除原因逐段登记。

比较时各方法同样收到恢复后截至当前时刻的所有合格位置，时延为0的自然数值流（与付费单点实验不同）：stale继续缺失前状态不接纳恢复数据、reset_decay首帧更新位置并衰减旧速度而不重估、stream首帧同reset_decay，第二帧起以连续两帧速度重新估计。三个方法共享可见信息，但前两者是故意不充分利用信息的消融；stream当前点可以直接定位，因此同时报告“更新前一步预测”和“收到后状态”，不能把实时观测误差0说成预测能力。

主指标为处理当前帧之前的单步预测误差，收到后的误差单列。旧球只做失配诊断，不在该比较中拟合新球。历史缓存仅合格连续帧构成，不使用坏段内部坐标。正式第一问和付费第二问不更改。
