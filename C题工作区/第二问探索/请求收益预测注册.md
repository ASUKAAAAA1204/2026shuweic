# 可见历史预测请求收益：固定实验注册

任务：预测开始前选择第一次请求时间；第二次固定.6秒。候选仅(.2,.6)、(.3,.6)、(.4,.6)，比较提前/原值/推迟，不扩大时刻搜索。delay=.1、预算2、同一阻尼secant引擎和实际末帧边界。

训练1527窗、全局环境留一；目标为候选相对(.3,.6)的逐窗NADE收益，两候选分别回归。仅使用预测起点前至多6个连续合格帧：最后速度、平均速度、速度波动、加速度、转向余弦、历史跨度及六帧不足标记；来源one-hot。空间量每折除以该折训练来源尺度，标准化参数仅训练折拟合。不足6帧时只用已保证合格的最后2帧，额外特征缺省并显式标记，不读取隐藏帧。

比较source_only（来源内分层等权平均收益）与history_ridge（来源＋历史，固定ridge=.1，截距不惩罚），预测最大正收益候选，否则原值。训练权重按来源、环境、记录、手别、窗口逐级等权。不调模型参数。保存所有候选逐窗真实误差与折外预测，报告NADE/FDE/超5%/成本、逐环境配对区间、选择比例。事后逐窗最优oracle只测三候选可利用空间，不进入合法策略，不代表全策略理论最优。开发和测试不读取；全项目已多轮探索，本轮也不是独立确认。
