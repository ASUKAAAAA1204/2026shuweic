# 初始速度历史候选结果

训练集机制筛查完成：更长历史可用，但直接平滑初速明显恶化预测。本轮不修改第一问或第二问正式模型，也不向已查看验证集迁移这些劣势候选。

这些证据反对将初始化误差简单归因于“两帧差分噪声过大”。更长窗口斜率对近期运动有滞后是可能解释，但本轮没有通过独立干预证明具体物理原因。也不能据此说所有初速模型无改进空间，更不能证明原两帧全局最优。

核验：独立事件循环从原始55训练记录重建四方案，逐窗误差与候选表最大差1.11e-16，分层汇总最大差1.11e-16；基线与旧结果差9.89e-17；首次返回后方案预测差0；无六帧支持时长历史回退差0。仍使用同一轨迹和数据清单，不能当成独立数据验证。
