# 返回后独立衰减机制试验

初始历史末两点速度与tau=0.2不变；固定0.3/0.6请求、delay=0.1、预算2不变。付费返回割线速度代表过去长间隔平均速度，与初始两帧速度信息不同，检验返回后共享tau=0.2是否不合适。

候选仅返回后tau=0.1、0.2、0.4，不拟合速度组合，不增网格。对每个持出全局环境，仅使用其余训练环境的分层NADE选择一个全来源共用tau，并列优先0.2再0.1再0.4。模型无需拟合系数，因此内层候选经验风险可直接由不含外层的固定候选结果形成，不需重复训练。外层只评分，报告NADE/NFDE/5%超差、来源及环境退化、同成本配对区间。仍属于受历史研究影响的探索，不访问开发/测试。

保留条件沿原预测门槛：NADE改善至少3%、名义区间下界正、来源退化不超过5%；同时披露超差及末帧代价，不自动覆盖正式模型。
