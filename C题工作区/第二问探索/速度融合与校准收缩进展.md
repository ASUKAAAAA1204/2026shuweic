# 已知问题修复进展：速度融合与校准收缩

本轮仅训练记录；第一问和原正式第二问模型未改；开发和测试均未读取。总目标仍未完成，不把研究负结果算成修复。

## 速度更新：五权重融合没有改善

同一tau=.2阻尼、同一0.3/.6请求、同一0.1秒延迟，7635次回放。割线权重0/.25/.5/.75/1的训练NADE依次0.096877/0.091628/0.087447/0.084296/0.082197。每个外层折的内层选择都回到权重1，严格嵌套评价与现有割线相同。

结论：旧速度融合路线停止细调；它不能解决已观察到的稀疏速度失配。不因此宣称全部更新方式无效。差异存在但不自动等于可用改进空间。

## 闭环校准：收缩有稳定性信号，但欠覆盖仍未解决

将当前开环球与已拟合的回传后球做固定权重插值，所有拟合残差均排除外层持出环境。只作训练OOF诊断，公开所有权重，不选择或升级新正式模型。

收缩权重0.5/0.75的分位损失改善区间不跨零，提示相对全量替换可减弱部分环境的波动。但0.75覆盖仅86.73%，仍低于预先设定87%总体下限；权重1覆盖满足总体目标，改善区间却跨零。不能同时满足全部既定条件，故本轮没有解决欠覆盖，不为通过门槛临时改阈值。

这些是多个固定候选的探索区间，不是多重比较校正后的确认结论。权重是事后诊断候选，不能把本轮当成全新无偏选择评价。下一轮必须训练嵌套选择并处理环境异质性，而不是继续按0.01步长搜索权重。
