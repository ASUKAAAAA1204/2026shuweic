# 环境块校准可行性注册

目标：检查恢复/缺失状态环境数是否足以给出有限校准范围，而非继续微调经验分位数。训练已有残差，不读开发/测试，不修改预测器。

按来源×状态构造环境最大原始残差，恢复单帧进一步分初始化/经历无效观测后。持出整个环境，校准分数只取其余同来源同组环境最大值，不跨来源回退、不归一化后拟合。固定考察80%和90%两档；m个校准环境的秩k=ceil((m+1)*coverage)，k>m时数学范围为无穷，接口明确拒绝有限范围，不能用最大值代替而仍声称目标覆盖。

有限时取第k个有序环境最大值。评价单位为“新环境该组所有已有可评分点同时覆盖”，不同于原逐点90%目标。另报有限输出率、有限组覆盖及归一化直径（尺度仅用于报告）。经典秩解释依赖环境交换性、固定预测器及同样采集/记录长度/分组规则；现有环境有操作者重叠和采集异质性，本实验不证明这些假设成立，不能对真实部署作形式保证。多个来源/状态不自动有联合90%保证。
