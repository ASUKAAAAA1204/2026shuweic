# 受限非线性请求收益实验注册

固定上一轮全部特征、三候选、训练环境留一与分层等权权重。不读开发/测试，不新增原始回放。仅比较一项非线性模型：多输出加权回归树，最大深度2，叶子至少60训练窗，每个特征只在当前节点训练值的10%至90%九个分位点候选处分裂，最小加权平方误差，叶子输出两候选平均收益。不搜索深度、叶大小和分位点。来源one-hot同原ridge；无额外特征。

预测最大正收益候选，否则fixed。保存每折树、拟合环境清单与折外预测。与fixed、原ridge和事后三候选oracle比较NADE、NFDE、超5%、成本与来源表现。改善必须稳定且不能以显著恶化末帧或成本为代价才考虑后续独立确认；不凭训练拟合成功推广。

这是多轮探索之后固定的一次诊断，不是独立预注册确认。若失败，结果只约束此容量和当前特征，不证明非线性方法或全部数据无效。
