# 自然恢复专用校准注册

仅训练已有自然恢复记录。主比较固定stream、0.2秒恢复窗，避免多时长重复计权。阶段=首帧(relative=0)与后续流帧。对照pooled为不分阶段的自然恢复残差球；候选phase为阶段分球。各外层拟合排除整个环境，来源/阶段至少2个环境及20个点才允许来源内拟合，否则回退跨来源归一化阶段残差并明示；不够则标记不可校准，不给虚假半径。残差先恢复为原单位，再按当前外层训练尺度归一化，避免不同外层归一化尺度混用。

必须分别报首帧和后续覆盖、半径、分位损失、参考事件/环境数与回退。整体覆盖不能替代首帧风险。经验90%球无形式化保证。数据少则登记证据不足，不通过放大球宣称已解决。不读取开发/测试，不替换正式模型。
