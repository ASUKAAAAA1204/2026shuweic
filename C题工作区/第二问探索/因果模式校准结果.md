# 因果可见模式校准结果

训练55记录、16全局环境；每时刻先预测，后接收当前有效性及位置。94092个手别时刻中93099个既有预测又有合格参考，其余993个完整计入不可评价/未初始化分母。未读开发和测试，正式方案未替换。

|校准|missing覆盖|recovered_single覆盖|tracking覆盖|
|---|---:|---:|---:|
|来源混合|7.00%|21.91%|89.28%|
|来源+因果前模式|83.40%|92.16%|88.95%|

对应分模式平均归一化直径约0.46224/0.10977/0.02269，分位损失约0.04311/0.00509/0.00142。来源混合球会把大量稳定流点的窄范围错误套给缺失和单帧恢复，因此其“半径小于5%容差”标记完全不足以认证。因果模式校准揭示了这种误导，并不是把实际位置误差降低了。

missing仍只有83.40%经验覆盖，来源层面回退平均约50%；该组当前已经合格才可评分，因此主要描述首次恢复前预测，并不代表坏段内部状态准确。所有真正不合格当前帧不计算真实位置误差。

recovered_single还包括记录初始化后仅收到一帧的情形，不应把92.16%全部当成坏段恢复性能。需进一步用仅依赖过去有效性记录的“初始化/经历坏段”标记区分后才作更细结论。tracking中大量平稳帧不代表遮挡困难已解决。

当前输出边界：missing继续不认证；recovered_single仅能给描述性范围，不能默认满足5%；tracking可输出经验半径与容差比较，但仍不宣称90%保证。empirical_within不等于certified。不得因标注不可认证而删去任务分母。

独立核验重算逐点覆盖、分位损失和完整层级汇总，结果见independent_audit.json；样本数见mode_counts.csv，资格分母见retention.csv。实现code/causal_calibration.py、注册《因果模式校准注册.md》。所有数值为后续训练探索，不是新独立测试结果。

总目标未完成：付费单点预测改进仍无成功候选；missing可靠性、严格5%容差、请求成本节省和独立泛化证据尚不足。本轮解决的是“用正常连续帧范围冒充缺失风险”的接口与统计混淆，不能把它等同全部性能缺陷修复。
