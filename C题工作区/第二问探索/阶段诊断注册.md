# 第二问作业阶段诊断注册

只使用训练1527个第二问窗口，按起点匹配原始语义区间[start,end)，所有训练语义区间均保留，不套用第三问1.2秒资格。报告无匹配、多匹配、与原始时间范围不一致、短区间及跨边界窗口，不删除难窗。

预先固定分组：任务族family_id；区间归一化进度三等分（early/middle/late）；实际评分末端是否越过起点语义区间末端。三等分不是人工确认的伸手/拿取/放置阶段。未来终点和文本仅用于离线诊断，不作当前策略输入。

比较现有open与secant固定请求的NADE、NFDE、超5%、成本，并按手别→记录→环境→来源等权；给出源/环境/记录/窗口覆盖，单环境小组不声称跨环境结论。检查各分组是否混杂任务族、来源和环境；描述相关差异，不作阶段因果解释。不读取开发和测试，不拟合新策略。
