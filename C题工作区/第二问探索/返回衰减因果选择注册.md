# 返回衰减因果选择固定试验

沿既有0.1/0.2/0.4三档，不增加参数网格。每次返回后，使用已知新旧位置形成的割线、此前已知速度、方向夹角、间隔及返回序号选择下一阶段tau。特征不使用当前返回以后参考轨迹。初始tau=.2、请求.3/.6与delay=.1预算2固定。

学习目标为该返回至下次返回/窗口结束的候选误差相对tau=.2差异。固定带截距ridge，标准化后正则.1，不调参；来源one-hot、阶段标志和有限运动特征。按全局环境留一训练，尺度与标准化均排除外层，输出各来源及全部共同指标。预测门槛仍3%/区间正/来源退化不超过5%；跨轮探索偏差披露。若无稳定收益停止本衰减选择分支。
