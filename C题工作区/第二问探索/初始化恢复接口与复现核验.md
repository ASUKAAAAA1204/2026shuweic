# 初始化／恢复接口与校准复现核验

本轮继续解决第二问已知问题，不改变第一问正式预测器、第二问既有正式结果或总目标。仅使用训练记录；开发与测试数据读取均为0。

## 已完成

1. 新增 `code/recovery_origin_interface.py`。根据已接收过的无效观测区分 before_any_invalid 与 after_observed_invalid；标签在当前帧到达前读取，不能提前知道当前帧是否恢复。该标签表示历史来源，不代表所有后续帧都处于即时恢复期。
2. 无效帧也纳入采样时间顺序检查；拒绝重复、倒序、非有限时间和非法有效坐标。输入验证失败不修改状态。拒绝以已接收的较晚信息计算较早时刻预测。
3. 全部55条训练记录、94092个手别时刻与旧接口配对回放，预测最大差异0；93099个可评分点的在线来源标签全部匹配先前离线标签。新版修复的是信息边界，不是精度提升。
4. 固化 `code/origin_calibration_experiment.py`，16个训练环境留一，236个单帧状态点、31个支持组；每折的残差归一化使用该折训练尺度。独立排序统计核验90%分位数，明确排除持出环境。与先前汇总最大差异5.55e-17。

## 结果与边界

|单帧状态来源|来源＋状态原有球覆盖|再按历史来源分球覆盖|新球平均直径|回退比例|
|---|---:|---:|---:|---:|
|经历无效观测后|83.06%|88.68%|0.104919|66.67%|
|尚未经历无效观测|94.62%|93.83%|0.078541|33.33%|

直径为训练尺度归一化值，不能解释为米或厘米。回退表示同来源支持不足时使用同历史来源的跨来源训练残差，不能因最终有支持便称同来源样本充分。两行按各自可评分集合分层等权统计，不能直接相减当成配对显著性检验。

来源细分确实缓解恢复组欠覆盖，但恢复组仍未达到标称90%，也未证明跨环境置信保障。这是看到原有结果后进行的探索，不是新的预注册确认实验。初始化整体表现较好不能掩盖恢复组风险。当前接口保留“不可认证”语义。
