# 自然恢复分阶段校准：问题定位与处理边界

训练79个手别恢复事件、14记录、10全局环境。固定stream接口、0.2秒恢复评价，逐点误差在接收当前帧之前计算。所有校准排除整个持出环境，残差先恢复原单位再用当前折训练尺度归一化。每来源/阶段不足2环境或20点时回退跨来源归一化残差。未读开发/测试、未替换正式方案。

|校准|首帧覆盖|首帧平均直径|后续流覆盖|后续流平均直径|
|---|---:|---:|---:|---:|
|混合恢复残差|44.26%|0.10602|93.25%|0.10602|
|首帧/后续流分开|91.20%|0.71453|84.50%|0.05182|

首帧占比较少，混合90%分位数主要受容易的后续流点影响，导致首帧欠覆盖。分阶段明显缓解首帧误差范围失配，但代价是首帧范围约6.74倍；该首帧误差在新位置到来之前产生，不能通过接收后误差为零掩盖。

分阶段首帧的来源/环境层级加权回退比例约73.33%，后续流约33.33%；这是加权比例，不是独立环境样本数量。说明来源专用首帧数据不足，91.20%属于有限训练跨环境经验结果，不是90%保证。后续流84.50%依然欠覆盖，整体问题未解决。

独立审计复算分位损失和覆盖，并核验首帧/流帧互斥、支持组与有限半径，见independent_audit.json。原bad坐标巨大扰动不影响恢复结果的检查已在前轮完成。本轮没有新增独立参考或新环境。

## 需要如何处理

1. 接口输出明确标记recovery_first与recovered_stream，不再使用一个“恢复后”状态概括全部。
2. 首帧收到之前，报告较高风险或不可认证；不将其预测当成已满足5%容差。首帧收到后更新位置，但这是观测接纳，非预测能力。
3. 后续流重新校准时需要稳定训练单步残差支持；当前自然恢复样本少，跨来源回退不可隐去。可与连续合格训练段共同建模，但必须先验证残差可交换性或进行收缩，而不是强行混合。
4. 当前数据无法证明首帧的严格小容差可靠性。应把“无法认证”显式作为输出/等待状态，并计入不可服务比例；不能删除难样本后宣布达标。

下一步将该分阶段风险标记纳入探索接口与报告，保持参考误差、范围和不可认证比例并列；同时核验这种风险输出不会借用恢复后未来帧。付费单点模式继续单独处理。
