# 初始速度条件范围固定试验

只分析首次付费返回前的固定两帧阻尼预测，不改位置模型。基线按来源×年龄格取训练90%误差分位数；候选额外按初始速度三等分分组，分界仅用外层排除环境后的训练窗口确定。速度按对应外层训练尺度归一化。残差归一化始终使用同一外层尺度，避免混用其他外层尺度。初始预测无拟合参数，因此校准可用其他环境的原始误差而不存在上游模型间接拟合泄漏。

每格不足100误差点或不足2个环境时回退同来源同年龄基线；基线年龄格不足100时回退同来源全龄。所有外层环境保留。速度分界相等时按searchsorted(side=right)分组，不按评价误差决定组别。不搜索组数、支持阈值和目标覆盖。候选范围在所有评分点只使用窗口前两帧速度、当前年龄和来源。

报告训练16环境留一的覆盖、平均直径、90%分位损失、条件回退比例、分来源/环境差异。仅当分位损失改善且覆盖与范围均可解释时考虑后续迁移；不因为覆盖提高就宣布最优。该试验受前轮路线选择影响，属于探索，不是新独立测试。验证/测试读取0。
