# 付费闭环校准迁移实验注册

问题：固定请求下残差校准改善，是否能转化为请求触发收益？自然连续恢复来源球不适用于付费孤立返回，本实验不混用。

候选固定为 fixed（.3/.6）、open_radius（全部使用开环年龄球）、post_pooled（首次成功返回后使用付费返回残差球）、post_env_mean（首次成功返回后使用环境内90%分位数均值）。不搜索阈值；归一化容差固定.05，延迟.1、预算2、单在途、1秒窗、secant更新，与现有正式协议相同。使用实际末评分时刻限制请求。

每个训练持出环境从其他全局环境拟合来源×年龄球。post_pooled每格至少100点否则回退开环；post_env_mean每个环境格至少20点且至少2环境，否则回退pooled。前三者在当前球超过容差时请求，不用当前参考误差触发。除固定策略外预设相同规则，不根据结果再调参。

报告分层等权NADE、FDE、超5%比例、请求数、等待以及实际闭环覆盖/球直径。校准用固定策略分布，而新策略可能改变分布，所以必须报告迁移后的覆盖，不把原校准覆盖当新策略保证。固定策略配对环境bootstrap用于探索诊断，不作独立确认。若误差或成本相对fixed无改善，或跨来源严重退化，不推广。开发与测试不读取。
