# 返回速度条件范围试验

仅基线固定两请求方案，返回后按最近已返回样本与前次已返回样本（首次用窗口前最后观测）计算割线速度。绝不在请求发出时使用待返回位置。速度三档边界由外层训练环境的返回事件等权三分位确定，各来源独立。两次返回合并同规则，不增阶段条件。

固定来源×年龄对照和额外速度三档候选，90%经验higher分位；不足100点或2环境回退对照。年龄仍从样本采样时间计算。16全局训练环境留一，所有归一化使用该外层训练尺度；预测无参数，其他环境的原始基线残差可用。报告覆盖、直径、分位损失与来源回退，保持点预测/请求不变。开发验证/测试不访问。此为探索，不承诺90%可靠性；不扩档数或阈值搜索。
