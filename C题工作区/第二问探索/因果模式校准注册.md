# 因果模式校准注册

只读55训练记录；每时刻先predict，再接收当前合格标记和位置。只在当前reference_candidate合格且有预测时计算误差。模式仅为预测前的missing/recovered_single/tracking，不用事后恢复首帧。将所有非合格时刻与无初始化时刻计入保留表。

两个固定对照：source_pooled（来源内合格单步残差90%分位）与source_mode（来源+预测前模式）。各外层排除整个全局环境；来源/模式少于20点或2环境，回退跨来源同模式归一化残差；仍不足则不认证并保留缺失。归一化一律用当前外层训练尺度。主目标是检查可见状态是否支持分层风险描述，不在本轮扩展参数、不基于已看开发/测试调优。

必须单独报告missing与recovered_single，不能让tracking的大量点掩盖风险。还需保留非合格无法评价的分母；合格参考覆盖不代表bad内部可靠性。
