# 环境等权闭环校准修复进展

本轮仅使用已保存训练残差，第一问、原正式第二问、开发和测试均未改动或重新读取。预登记4候选，所有半径排除外层全局环境。

环境等权均值候选最低来源覆盖87.51%，范围相对开环增长20.58%，分位损失改善10.46%，满足原数值门槛。相对按帧回传后球，损失差很小（约0.17%），不应描述为巨大算法突破；主要价值是相对开环球的闭环匹配，并在环境权重上更接近评价目标。

独立复算1440组环境支持，汇总最大差5.55e-17。额外10000次环境bootstrap，9595次含全部来源；单项95%改善区间约[0.71%,17.52%]，三项Bonferroni校正区间[-1.92%,19.09%]仍跨零。因此只能作为有希望的探索候选，尚不足以宣布闭环欠覆盖普遍解决；也不能升级为概率保证。此前尝试过的其他方法使总体研究选择偏差比单次三项校正还复杂，不能将校正当成独立验证。

下一步在训练环境内嵌套评价校准规则的稳定性，补充0/.1/.2延迟和首次/第二次返回、自然坏返回情形；不重看已使用开发或最终测试挑参数。只有预登记主对比、范围和分源覆盖共同满足且稳定性证据支持，才更新探索版方案。原正式方案的历史结果必须保留。
