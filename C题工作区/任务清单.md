## 1. 当前优先：数据集处理与审计

### 1.1 规则与字段侦察

- [ ] 通读第三问完整要求和数值配置，形成规则对照表，登记冲突与未明确事项。
- [ ] 每源选一条记录，读取元数据、轨迹、质量和语义区间，建立最小读取脚本。
- [ ] 核对全部文件schema差异，建立字段字典：含义、类型、形状、单位、坐标系及缺失编码。
- [ ] 核对左右手、21关键点索引、姿态表达、相机参数与质量标记。

交付：字段字典、schema差异表、三源读取脚本、规则对照表。
验收：关键字段含义有原文件依据；未知字段不凭名称猜测；三源均能读取。

### 1.2 身份索引与官方划分

- [ ] 读取episode_uuid、environment_id、scene_id、operator_id，建立原文件路径映射。
- [ ] 按UUID查跨源重复，区分相同内容与冲突记录，保留审计记录。
- [ ] 连接官方record_split，统计唯一记录、环境及各源数量。
- [ ] 检查训练/验证/测试环境互斥及scene/operator重叠；未匹配记录隔离。
- [ ] 让后续区间与样本继承记录split，禁止按帧随机切分。

交付：records_manifest.csv、split_audit.csv、duplicates.csv。
验收：每条记录有唯一身份和明确split；差异有原因，不强改数量以符合题面。

### 1.3 时间与坐标核对

- [ ] 识别原始时间单位、起点、视频PTS/帧号及多通道时间关系。
- [ ] 统计单调性、重复、乱序、采样间隔、缺口和通道匹配误差。
- [ ] 验证坐标单位、轴向、变换方向；抽样画轨迹并与视频对照。
- [ ] 各记录保持独立坐标原点，不拼成共享店铺地图；不虚构腕部世界外参。
- [ ] 分开定义离线对齐与在线因果对齐，不让未来样本参与当前特征。

交付：时间审计表、坐标约定、抽样核对图。
验收：单位和变换清楚；不跨缺口或记录形成假连续轨迹。

### 1.4 质量审计与清洗规则

- [ ] 统计缺失、NaN/Inf、异常形状、时间缺口、质量原因与关键点可用率。
- [ ] 先展示异常分布，再依据物理含义和训练数据制定阈值，记录候选规则。
- [ ] 分别标记可拟合、可作参考、低质量分析及排除用途，不简单全部删除。
- [ ] 自然遮挡和near-edge区间单独保留，统计发生、持续和恢复。
- [ ] 不把插补、平滑值当参考真值；原始与处理后数值、质量标记并存。
- [ ] 输出分源、split、环境、手别的清洗前后数量及排除原因。

交付：quality_audit.csv、exclusions.csv、清洗配置及数据审计报告。
验收：每次处理可追溯；阈值未用测试表现调优；数据保留数量可核对。

### 1.5 语义区间与时长审计

- [ ] 核对标注起止、时长、重叠、越界及端点约定。
- [ ] 将source_segment_index连接真实记录，核验349区间及343个eligible区间。
- [ ] 按任务族、来源、split和环境统计时长、样本量及异常。
- [ ] 检查0.2/0.6/1.0秒前缀实际样本数和可用通道，不提前插补协议原始前缀。
- [ ] 明确训练标签与策略可见字段；真实时长、源标识、语义描述等按协议隔离。

交付：segments_audit.csv、prefix_availability.csv、分组时长统计。
验收：索引能定位真实区间；每个前缀的可用信息边界明确。

## 4. 候选方法比较与选择

- [ ] 针对已识别瓶颈提出少量候选方案，逐项写明假设与预期收益。

- [ ] 用消融区分状态/时长模型、信息规则、预留和排序的贡献。
- [ ] 记录改进无效或变差的情况，允许保留简单基线作为最终方案。
- [ ] 小实例能精确求解时检查最优差距；无法证明全局最优时限定结论措辞。
- [ ] 仅依据验证集选择模型、阈值与偏好，冻结后才做最终测试。
