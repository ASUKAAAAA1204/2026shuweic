# S4 前瞻代理定义补充（执行前登记）

BudgetPolicy 不宣称真实VoI。它以训练校准半径的时间积分代理未来误差，比较不请求、现在请求、稍后请求；如剩余两次额度，可在首次返回到终点的中点加第二次假设请求。稍后候选为当前剩余时长/(剩余额度+1)。采用12个均匀公开时间点近似积分，减去归一化成本权重。比较只用已知窗口终点、当前观测年龄、剩余额度、延迟、训练半径；不访问未来轨迹。并列时不请求。成本权重严格使用注册的四个数，不另增搜索。

这是轻量预算前瞻的可证伪候选，不等于原外部报告VoI，也不假定半径更新能精确预测返回后的真实误差。每个外层及内层持出环境均从校准拟合与尺度拟合排除。校准半径可能不足以支持该代理，负结果如实保留。
