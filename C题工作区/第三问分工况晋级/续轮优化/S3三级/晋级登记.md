# S3 第三级登记

以续轮冻结清单的 S3 二级调度为唯一直接对照。S1 与 S2 使用原发布入口，锁定参数和代码。本次只修改 S3 的独立实验目录和交付说明，不制作或改动图片。

每轮先用既有开发种子筛选、冻结一个 S3 候选，再打开新的配对验证组。第 r 轮配对验证使用从 6810000 + 1000 × (r−1) 开始的连续 640 个种子，各轮互不重叠。每种子按原协议在同一个验证池中抽取一次隐藏时长，二级与候选共享同一份实例。训练模型只使用训练区间，允许用已结束任务的公开反馈更新当前实例估计。开发筛选使用已用的组，不读取本轮或后续晋级种子的成绩。一个候选首次提交给新组计一次优化轮；开发候选数量另列。失败后更换机制或参数，严禁只换种子重试同一候选。

同组同时满足三项即停止搜索：

1. 候选的平均加权按时率 ≥ 0.850000。
2. 新版减二级版的逐种子加权按时率差，双侧 95% 配对百分位自助区间下限严格大于 0。按种子重抽 10,000 次，随机源固定为 66517。
3. 新版的平均加权完成率 ≥ 同组二级版完成率，按未舍入值比较。

逐次检查预算、前驱、时间及非法动作。按晋级组实测报告完成率、成本、拖期、区间及轮数。新种子共享原验证来源池；区间按单个冻结候选计算，并披露所用轮数。优先尝试按公开前缀的采样与运动特征预测各任务时长，结合已完成任务的反馈，再检验路线搜索。
