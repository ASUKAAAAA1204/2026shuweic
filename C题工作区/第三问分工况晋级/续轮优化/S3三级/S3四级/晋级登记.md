# S3 四级新种子晋级登记

唯一对照为上一发布入口的 S3 三级。S1、S2 直接沿用原冻结实现。以每个种子的任务权重加权按时率、完成率作为观测，再按种子等权平均。

每轮在已有开发种子上筛选，先锁定一套候选和执行代码，再开启一个全新的固定样本组。每组 2048 个种子，第 r 轮从 7820000 + 3000 × (r−1) 开始。样本量在看到新种子前确定，给约半个百分点的改善留出区分空间，轮内不提前查看或调整样本量。新旧策略逐种子共享源区间、任务、预算和总时限。

每轮同时计算新版均值的双侧 95% 百分位自助区间，以及新版减三级的配对均值差的双侧 95% 区间，重抽样单位为种子，使用相同的 10,000 组索引，随机数种子 557221。按未舍入值要求：自身下限 ≥ 0.85；增益下限 > 0；平均加权完成率 ≥ 同组三级。每次回放还须通过合法性、费用、复核数和独立计分检查。首次满足全部条件立即停止搜索，只在同一批记录上核验。区间按每个冻结候选分别计算，报告所有正式尝试与开发筛选数量。

沿用 440000–440479 及已公开的上一版回放作为开发资源；旧成绩与上述新种子严格分开。首批考察训练信息稀少的任务族的时长先验以及实例内反馈，再视开发表现比较分层估计和更新策略。估计参数所用训练区间必须来自训练划分，调度器只接收公开任务与已完成反馈。正式比较仅代表既有验证来源池。图片不改。
