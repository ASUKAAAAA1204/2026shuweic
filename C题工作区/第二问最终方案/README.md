# 第二问当前采用方案：完整复现交付

本目录只收录当前采用的方案及其运行结果，不含候选筛选、淘汰方案或搜索代码。模型参数沿用已冻结版本，本次重新读取全部原始记录进行推理和计分，没有重新选模或调参。

## 采用方案

每手21关键点均值作为三维状态；用遮挡前最后两个有效位置估计初速度，采用时间常数0.2秒的阻尼恒速外推。在相对0.3、0.6秒发起付费观测，延迟0.1秒，预算2次；返回后按样本时间计算割线速度，并在到达后更新状态。评分前处理已到达返回，策略不可访问未来参考轨迹。

预测球使用首次返回前、返回后两组连续条件90%分位数模型，输入为观测年龄、年龄平方、归一化速度的log1p及其与年龄交互项。各来源独立拟合，训练阶段使用留一环境参数；验证和测试使用完整训练集冻结参数。半径是经验误差范围，不具有90%理论覆盖保证。

## 与原误差范围的区别

验证集原来源/时长范围覆盖率83.90%、直径0.353562、分位数损失0.018488；当前范围覆盖率88.05%（提高4.15个百分点）、直径下降约2.41%、损失下降约18.48%。位置预测未更换，因此不能将范围改善表述为位置精度提升。该对比来自此前实验；本次重新运行的是当前采用方案。

## 证据边界

验证和测试此前均已被查看，本次属于复现评估，不能宣称新增独立泛化证据。训练留一环境使用既有冻结折参数，本次未重新训练。测试总体覆盖率超过90%不意味着各来源、各阶段都达到90%。官方 missing_observation_experiments.md 仍缺失，当前为自定义固定付费观测协议，不能宣称已验证未知官方评分规则。

本交付完整运行的范围为当前采用的1秒窗口、0.1秒延迟、两次固定请求协议。尚未证明自适应请求优于固定请求；不把此范围模型用于自然缺帧恢复或其他延迟，并且不声称第二问所有研究缺口已解决。

## 复现

依赖 Python、numpy、pandas。数据不随 Git 上传，传入包含 records/ 的官方解压目录，以及既有 windows.csv：

```powershell
python code/run_complete.py --data-root "官方数据/v1/v1" --windows "窗口清单/windows.csv"
python code/verify_outputs.py
```

从本目录执行。run_complete.py 使用脚本所在目录定位参数和输出，不依赖探索目录。model/model.json 为完整训练参数；oof_prior.json、oof_return.json、fold_scales.json 为训练留一环境所需参数。results/ 包含逐点评分、逐窗口指标、全部请求/返回日志、来源/环境汇总及输入哈希。代码名 candidate_replay_engine.py 是既有接口名，仅包含当前方案使用的回放引擎，并非候选试验集合。
