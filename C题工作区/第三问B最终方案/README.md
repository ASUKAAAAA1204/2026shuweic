# 第三问最终方案：B_K64联合场景前瞻

用户最终确定采用B_K64；E和修正版C为对照。历史E验收包保留为审计记录，不代表当前采用决定。

方法：训练族/全局收缩分布与实例内完整执行反馈；每次生成64个联合时长场景，候选首动作共享随机数，逐场景回放尾部基策略，以平均按时权重选择首动作。最小预留0.2秒，不购买复查。每实例重建Policy，反馈不跨实例累积。

标称按时率90.9606%，基线85.0926%，提高5.8681个百分点、相对6.8961%；五映射平均88.9606%。B两折环境留出差值为−0.6250、+1.8056个百分点；须保留迁移局限，不宣称全面最优。

默认Policy()已切换为B_K64。运行 `python code/run_all.py --methods baseline,B_K64` 复现900次配对试验。完整四方法比较可运行 `python code/run_all.py`。依赖numpy、pandas，版本见environment.json。包内含训练模型与离线验证抽样池，策略不读取隐藏池。

论文方法、原始比较与独立核验详见相邻第三问突破优化/parallel/B_联合场景前瞻/report.md及CBE采用准备/三项验收报告.md。
