# 本阶段执行计划、目标与交付门槛

目标：完成数据收尾、冻结协议、三问基线与可信评估器、独立复现和结果报告。最终论文、模型增强和组织方最终测试属于下一阶段。

|顺序|工作|量化门槛|
|---|---|---|
|A|数据收尾与语义依赖审查|69身份唯一；345通道逐源数值回查；1029前缀一致；184视频全解码；每源3记录视觉核对|
|B|冻结状态与实验协议|两问均为21点中心；固定1秒窗口、0.2秒历史、窗间1秒；train/validation/test按官方环境保持|

硬门槛：验收清单全部通过、阻断项0，才标记本阶段交付。基线效果不佳允许交付并报告，不允许为满足成绩删除失败样本。

冻结选择：不使用未核实腕点/四元数/物理单位/相机投影，统一21点中心；问题二官方说明缺失，采用研究协议并明确标识；test仅结构审计。所有窗口和模型参数在比较前生成/拟合，文件哈希记录版本。

重要解释：CSV质量global标记在本基线保守共享双手，虽然原始problem_type原因含left/right，暂不把更细原因反推为未经官方说明确认的另一手物理真值。每个原始原因保留并分组报告。此规则会扩大排除范围和可靠性标签影响范围，报告会明确说明；后续细化手别质量属于受控版本变更。

执行入口：scripts/baseline/run_pipeline.py。全流程默认附带独立目录重跑；阶段产物位于阶段交付/baseline_v2。最终状态与证据见验收结果.json，不能以本计划替代验收。
