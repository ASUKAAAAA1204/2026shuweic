# 统一数据字段字典与处理约定

所有records文件都由record_index.csv定位；不要按帧随机拆分训练测试。NPZ用numpy.load(..., allow_pickle=False)读取。数值数组保持原值，转为float64仅改变容器精度，不恢复源float32已损失精度。

|后缀|形状/类型|定义|
|---|---|---|
|`__t_s`|N float64|源记录相对秒；不同通道独立保存|
|`__timestamp_ns`|N int64|CSV原始log时间，Demo不生成伪纳秒|
|`__publish_timestamp_ns`|N int64|CSV原始publish时间|
|`__source_offset_s`|N float64|CSV原始相对秒字段|
|`__frame_index`|N int64|Demo原始frame_index|
|`__position`|N,J,3 float64|源世界位置，xyz，物理单位与轴向待核实|
|`__quaternion`|N,J,4 float64|CSV按明确wxyz列；Demo按元数据声明qw qx qy qz原顺序保留|
|`__finite`|N bool|全部位置和四元数有限|
|`__quaternion_unit_1e3`|N bool|所有J范数偏差<=0.001|
|`__time_increasing`|N bool|首帧True，随后t大于前帧|
|`__gap_before`|N bool|与前一帧间隔>通道正间隔中位数3倍|
|`__quality_known`|N bool，仅双手|能映射到源质量标记；Demo稀疏未列出按未标坏约定|
|`__bad`|N bool，仅双手|Demo按手别reason，CSV全局is_bad保守共用|
|`__reference_candidate`|N bool，仅双手|finite且单位四元数且质量已知未标坏且时间递增；不是物理真值|
|`__wrist_position`|N,3，仅双手|transform0位置，Demo名称为wrist；CSV关键点对应待官方确认|
|`__wrist_backward_velocity`|N,3，仅双手|后向位置差/正dt；两端必须参考合格且不跨gap；其他NaN；原坐标单位/秒|
|`quality__timestamp_ns`、`quality__bad`|M|CSV原始质量序列，独立保留|

通道前缀：left_hand、right_hand、head、head_left_camera、head_right_camera。双手J=21，其余J=1。head_left_camera对应CSV pose_headcam，head_right_camera对应pose_right_eye_cam，命名映射有源文件依据，变换方向尚未通过物理标定验证。

Demo关键点命名和features、内部episode元数据、CSV原始质量原因、相机原始字段全部保存在metadata_private.json。相机内外参不参与本轮轨迹坐标变换；Demo8维内参排列缺正式字典，不擅自推成K。视频不转成模型前缀。

问题三前缀仅含五通道t_s/position/quaternion及双手quality_known/bad，共19数组；t_s减去区间起点。它不含完整时长、语义、UUID、绝对日期或帧号。缓存路径仅可信评估器可见。

人工遮罩候选的end_index_exclusive是下一个可见样本索引，隐藏[start_index,end_index_exclusive)，不能把隐藏区间中的值送入恢复算法；原值只供评估误差。候选窗口需要在实验前选成不重叠集合或按记录聚类估计不确定性。低质量自然区间没有真实隐藏值，不能直接拿作恢复误差真值。
