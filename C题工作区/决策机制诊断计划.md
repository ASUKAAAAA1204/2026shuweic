# 决策机制受控诊断计划

目标：解释请求预算饱和与调度首次分歧的实际贡献，不搜索新参数、不训练新模型。

1. 使用既有E2主条件（延迟.1秒，容差5%）全部验证回放，统计首/次请求时间、0.3秒前预算耗尽比例、两策略请求时刻是否一致。仅事后诊断，不据此重调验证阈值。
2. 使用E3全部180组名义训练配对试验，复现源抽样和族中位数。找到两策略首次动作分歧，保留共同历史，在前瞻策略中仅该次采用基线动作，然后恢复前瞻，比较按时率。没有分歧则不干预。
3. 动作替换只用当时公开状态与基线动作，不用未来真值选动作。真实时长只供可信评估器回放；结果只能解释这一策略干预，不能分解所有误差因果。
4. 原始两策略复现误差<=1e-9、替换过程违规0；所有组保留，禁止只报告改善样本。统计先环境/case再等权。
5. 输出表、检查和结论；下一轮模型或请求规则变更需新协议。test不参与。
