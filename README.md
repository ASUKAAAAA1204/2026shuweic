## 最新 S3 晋级结果

S1、S2 沿用冻结版本。S3 四级在第 5 轮首次晋级。该轮 2,048 个新种子上的加权按时率为 85.5225%，自身 95% 区间下限为 85.1745%。相对同种子三级，按时率增加 0.5341 个百分点，配对增益下限为 0.3418 个百分点，完成率增加 0.3601 个百分点。[四级晋级报告](C题工作区/第三问分工况晋级/续轮优化/S3三级/S3四级/晋级结果.md) · [三个工况的调度入口](C题工作区/第三问分工况晋级/续轮优化/S3三级/S3四级/deploy.py) · [三级历史结果](C题工作区/第三问分工况晋级/续轮优化/S3三级/晋级结果.md)

## 三问正式联合回放（S3 四级）

第一问采用旋转位置模型和训练留环境残差误差球，第二问采用旋转起步并在首次有效返回后切换阻尼。第三问名义映射使用冻结的 S1、S2 和 S3 四级，其他映射沿用截止机会损失调度。在原有的 30 个验证种子上，三工况等权按时率较上次正式联合回放由 90.1273% 升至 90.6829%。在四级晋级原批次的 2,048 个种子上，整体按时率较三级由 89.8522% 升至 90.0302%。

## 数据与复现

原始比赛资料、往年论文、原视频与轨迹、压缩包、运行依赖、完整处理数组和逐动作JSONL日志未上传，保留于本地。仓库保留汇总、逐试验CSV、代码和校验清单；因此仅克隆仓库不能直接执行全量复现。

使用合法取得的比赛附件恢复 `C题工作区/数据集/{EgoDemo,EgoPro,EgoStandard}` 及 `C题工作区/Restocking_Problem_and_Data_EN`，使用Python 3.14并按阶段交付目录内requirements-lock.txt安装依赖到 `C题工作区/运行依赖314`。先执行scripts中的process_dataset.py、finalize_processing.py、additional_audit.py生成v1数值产物，再运行：

```powershell
python C题工作区/scripts/baseline/run_pipeline.py --reproduce
```

程序会全量解码视频、生成模型和结果，并在独立目录复现。日志与数组在本地生成。源文件和代码哈希用于检查输入版本。
