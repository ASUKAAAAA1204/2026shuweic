# 四题研究方向、知识要求与难度量化

日期：2026-11-20。适用目标：在竞赛时限内完成全部小问、有可复查程序和必要验证的英文论文。依据：本地四题正式题面、已读取的附件配置，以及《00_四题全面分析与选题报告.md》。不假定团队已具备油藏、机器人或天体力学专长。

## 1. 先明确量化能说明什么

题目难度没有天然的客观分数。本报告给出的是**公开尺度、公开权重、逐项有依据、能够重算的决策模型**，不是实测耗时、官方难度、成功率或获奖概率。四题样本不足以统计估计这些概率，因此不编造置信区间或“获奖率”。

评分对象是达到完整且可信交付的工作负担，不是只做出一张图或跑通一个算法的门槛。以一般数学建模基础、熟练Python、常规个人电脑、尚未证明有领域专长的团队为基准。硬件、经验和已完成代码会改变排序。分数只用于本次四题横向比较，61分不表示完成了61%的工作，也不表示比另一题节省某个比例的时间。

**当前结论：B的完整交付负担最低；A和C均重，C的数据与实验工程负担最高；D总工作量未必最大，但理论成立性风险最高。** D的理论风险不能被较低数据工作量抵消，所以必须同时查看总分和关键门槛。

## 2. A题：油藏开发的多物理场与工程优化

### 2.1 涉及的研究方向

主方向：油气藏工程、多孔介质多相渗流、岩石孔隙弹性与损伤力学。交叉方向：组分传输、纳米颗粒吸附、无量纲分析、多目标与稳健优化、代理建模、工程经济与全局敏感性分析。

这是“物理模型驱动的预测和决策”问题。机器学习仅负责题目规定的数据比较或加速计算，不能替代第一问的物理闭合关系。

### 2.2 必须掌握的知识

|知识模块|最低掌握程度|对应任务|不掌握的直接后果|
|---|---|---|---|
|多元微积分、散度、偏微分方程|能从控制体写守恒式、识别未知量与边界条件|第一问|方程数量不足或边界过约束|
|Darcy、多相饱和度、相对渗透率与毛管压力|能说明各相通量和闭合关系|第一、四问|产油水量与注入过程不一致|
|线弹性、Biot有效应力、损伤不可逆性|能统一应力符号并写耦合反馈|第一问|耦合停留在术语拼接|
|对流扩散、Henry平衡、吸附|能区分压力传播、物质扩散和颗粒滞留|第一、二问|错误解释作用半径与焖井时间|
|无量纲化、尺度分析|能给特征尺度、无量纲参数及适用条件|第二问|只写平方根关系而无条件证明|
|数值离散与稳定性|能做守恒、网格/时间步收敛和阶段切换|第一至三问|优化建立在不可信模拟器上|
|Pareto与随机扰动|能处理工程约束并检验±15%扰动|第三问|只给单目标解或不稳健推荐|
|分组验证、代理模型、NPV|能按完整曲线分组、计算逐日现金流|第四问|泄漏或重复计算累计收益|

进阶加分知识：有限体积/有限元、裂缝降阶、Sobol/Morris、代理误差传播。不是必须同时使用所有高级方法。

### 2.3 能力链与最低交付

第一问耦合模型 → 第二问尺度解释 → 第三问三场景六变量约束优化 → 第四问数据模型对照与经济选择。四问共用物理定义，前一环错误会传到后续。

最低能力证据：独立写出一个守恒的一维降阶算例，正确切换注入/封井/生产；经济例账一致；模型能解释附件未覆盖的其他操作变量。仅会COMSOL界面或调用NSGA-II不能替代这些能力。

## 3. B题：几何定位与多车协同调度

### 3.1 涉及的研究方向

主方向：计算几何、方位交会定位、运筹优化。交叉方向：传感器几何设计、随机误差传播、障碍物路径规划、多资源同步调度、事件驱动重调度。

这是“可行空间—信息精度—时间资源”的联合优化。目标高度给定，解的是水平交会定位；不需要训练无人机识别大模型，也不要求完整飞行控制系统。

### 3.2 必须掌握的知识

|知识模块|最低掌握程度|对应任务|不掌握的直接后果|
|---|---|---|---|
|解析几何与三角函数|坐标转换、仰角、距离、角度wrap|第一至三问|角度单位或方位定义错误|
|计算几何|圆盘车辆与矩形建筑碰撞、线段与三维盒相交|第一、二问|站位可见但车到不了，或擦边遮挡漏判|
|路径规划|在膨胀障碍域计算合法路径及时间|第二、四问|用穿楼直线距离制造假方案|
|线性代数与统计|Jacobian、协方差、信息矩阵、正态概率|第二、三问|精度评价与退化处理失真|
|离散与连续优化|枚举车辆对、候选站点筛选、连续细化|第二问|局部或网格结果误称全局最优|
|同步资源调度|双车等待、5秒观测、复位后再出发|第二问|时间轴重叠、车辆瞬移|
|事件仿真|t=5冻结状态、故障/断联/新目标触发规则|第四问|使用未来信息重写历史|
|Monte Carlo及配对比较|共同场景与种子、阈值概率验证|第三、四问|优化与基线不可公平比较|

进阶加分知识：混合整数优化、分支定界、信息几何、滚动时域控制。无需先掌握深度学习或完整SLAM。

### 3.3 能力链与最低交付

可观测域 → 精度最优双站 → 五车三任务复用 → 误差预算与扰动调度。第一问和第三问相对独立，可用于尽早取得可验证结果；第二问后半和第四问是主体难点。

最低能力证据：障碍几何边界算例通过；每车事件时间严格守序；同一目标两车同步；观测开始与完成指标分清；与最近分配基线比较公平。

## 4. C题：观测不确定性下的状态估计与信息决策

### 4.1 涉及的研究方向

主方向：统计信号处理、状态空间建模、部分可观测决策与随机调度。交叉方向：机器人示教数据分析、观测质量评估、缺失数据机制、主动观测、信息价值、服务时长预测、风险预留、实验可复现性。

核心是人类操作记录驱动的状态与决策研究。商品三维几何、抓取成功和真实机器人性能并非已有真值，不能由手轨迹直接替代。视频体积大不意味着必须训练视觉网络。

### 4.2 必须掌握的知识

|知识模块|最低掌握程度|对应任务|不掌握的直接后果|
|---|---|---|---|
|异构数据工程|读取JSON/Parquet/MCAP、统一时钟/坐标/质量标记|第一问|三源数据不能合并或含义误读|
|状态空间与滤波|状态转移、观测方程、噪声与缺失更新|第一、二问|只平滑轨迹，缺失预测无依据|
|概率统计与校准|预测区间、覆盖率/宽度、参数不确定性|第二问|置信度过度自信或无限放宽|
|缺失数据与实验设计|人工遮罩与天然低质量区间分开、因果时间顺序|第一、二问|没有可靠参考仍计算真实误差|
|数据分割与泄漏排查|按环境划分、冻结模型、限制当前可见前缀|全部问题|测试结果被环境或未来信息污染|
|信息价值与决策|再观测成本、延迟、等待的联合权衡|第二、三问|请求信息提前到达或无限免费观察|
|分位数/时长模型|只用当前可见数据预测服务时长分布|第三问|查真实结束时刻造成作弊式优势|
|单设备调度与离散事件仿真|释放、前驱、预算、预留、超时终止|第三问|程序结果不满足共同协议|

进阶加分知识：切换状态空间、POMDP近似、分布稳健调度、保形预测。无需直接实现完整POMDP精确解。

### 4.3 能力链与最低交付

原始数据审计 → 状态/质量模型 → 带延迟再观测 → 预测时长与预留 → S1/S2/S3共同协议比较。数据工程是前三问共同前置任务，难以靠后补写解决。

最低能力证据：三个数据源均能读取；环境切分可复核；人工遮罩无派生特征泄漏；模拟器准确处理s+p与s+max(p,b)的区别；相同任务和种子下比较。题面给定五种映射×三场景×30试验，对每方法形成450个试验单元，但其单次耗时要试跑后才可估计。

当前附件说明缺口尚未排除，给数据与协议不确定性附加关注；不能据外层解密成功就认为原始记录已经可用。

## 5. D题：观测投影、轨道动力学与长期分布

### 5.1 涉及的研究方向

主方向：天体力学、非线性动力系统、几何观测。交叉方向：逆问题与可观测性、中心力轨道、共振与进动、常微分方程数值积分、长期经验测度与等分布。

难点在命题成立条件，而不是画轨道的计算量。题面期望的“均匀轨道环”和“单一动力学中心”需要被精确定义并研究，不能预设为无条件真命题。

### 5.2 必须掌握的知识

|知识模块|最低掌握程度|对应任务|不掌握的直接后果|
|---|---|---|---|
|三维旋转、正交/透视投影|区分日心真实轨道、地心视运动和相机投影|第一问|把观察变形误判成动力学变化|
|经典力学|角动量、能量、中心力、质心参考系|第二问|指定的径向与角向振荡互相矛盾|
|常微分方程|从力模型积分轨道，检查稳定性与守恒|第二、三问|画出参数曲线却无动力学依据|
|周期与准周期|频率比、径向周期累积方位角、闭合判据|第二问|稠密轨迹被误认定周期闭合|
|长期统计/测度概念|区分轨迹覆盖、旋转对称、时间分布与面积均匀|第二、三问|用环状图片代替均匀性证明|
|可辨识性与反例|说清观测条件、必要/充分条件、模型适用域|全部问题|把有限样本不足泛化为普遍不可能|
|数值误差分析|步长/时域加倍检查、等时间采样|第三问|数值漂移冒充真实进动|

进阶加分知识：Hamilton系统、作用角变量、辛积分、遍历与等分布理论。广义相对论若不作为定量主模型，不必在竞赛中完整推导其场方程。

### 5.3 能力链与最低交付

投影模型 → 物理兼容的双振荡模型 → 闭合/非闭合条件 → 长期分布及反例 → 数值验证。没有外部观测数据，内部一致性验证不能替代对真实行星的经验验证。

最低能力证据：能指出独立设定r与θ何时违反r²θdot守恒；能构造闭合与非闭合例；能解释为什么稠密不等于面积均匀。若只能生成漂亮环形图，尚未跨过第二问核心门槛。

## 6. 难度量化模型

### 6.1 八个维度和统一锚点

每项整数1—5分，表示从低到高的交付负担。1为现成直接任务，3为需要独立组合成熟方法，5为多个强耦合环节或关键命题/证据缺口。2和4为相邻锚点中间状态。各维度尽量拆开：知识是“需要懂什么”，推导是“需要证明什么”，工程是“需要实现什么”，验证是“如何证实结果”。仍可能相关，故分数不解释为独立风险概率。

|维度|权重|1分锚点|3分锚点|5分锚点|
|---|---:|---|---|---|
|K 领域知识跨度|20%|常规本科方法足够|一个领域专门知识加交叉方法|多项专业理论需要一致使用|
|M 数学推导深度|15%|直接代入|独立推导近似/约束模型|非线性耦合或长期性质需严谨论证|
|D 数据准备负担|10%|题面参数可直接整理|一种复杂数据或常规清洗|多源格式、时空语义与质量需统一|
|E 实现与集成负担|15%|单脚本计算|数个模块可分别运行|多阶段数据/预测/决策系统严格联动|
|C 计算与搜索负担|10%|解析或极小枚举|低维搜索及重复模拟|昂贵数值模型嵌套优化和不确定性计算|
|V 验证与证据负担|15%|直接核对或解析真值|基线、误差与参数敏感性|参考不完美/长期命题/多层协议需同时验证|

## 7. 防止总分掩盖瓶颈

另取瓶颈指标G=max(K,M,V,U)，得到A=5、B=4、C=5、D=5。任何关键门槛不通过，总分再低也不能视为可交付。

## 8. 评分不确定性与权重敏感性

采用三种透明复算，避免单一权重决定结论。以下区间是确定性的评分扰动范围，**不是统计置信区间**。

1. 单项评分误差：任一维度上下浮动1分且截断1—5。最大权重20%，所以总分变化至多4分；C与A的细分次序可能翻转。
2. 核心未决项：A的实现/计算/不确定性各±1，范围79—91；B的推导/实现/不确定性各±1，范围53—69；C的数据/实现/验证/不确定性各±1，范围79—91；D的推导/验证/不确定性各±1，范围73—81（其三项已全为5，上调被截断）。范围重叠提示高难题内部排序不稳定。
3. 两组替代权重：理论侧重K/M/D/E/C/V/U/L=20/25/5/10/5/15/15/5；工程侧重=10/10/20/25/15/10/5/5。

|权重方案|A|B|C|D|解释|
|---|---:|---:|---:|---:|---|
|基准|86|61|89|81|完整交付负担|
|理论侧重|89|63|87|89|D理论难度明显上升|
|工程侧重|80|59|92|67|C数据与系统集成更突出|

三个方案中B均最低；A/C/D的顺序随评价重点改变。D的较低工程分不能消除核心理论门槛。替代权重是情景分析，不代表团队真实偏好。

## 9. 把“题目难”转成“我们做起来难不难”

团队应逐维提供能力证据，而不凭“学过这门课”自评。熟悉某软件不能自动把推导与验证难度降分。建议在试跑后更新K、D、E、C等分数，每次调整保留理由与代码/结果链接；题目本身要求不随团队偏好删除。

|团队已具备的能力|更适合的题目|仍不能省略|
|---|---|---|
|油藏/岩土、多物理场数值模拟且能写经济模型|A|尺度推导、分组验证、稳健性和NPV账务|
|几何算法、概率统计、运筹与事件模拟|B|三维遮挡、双车同步、复位时间与基线公平|
|MCAP/轨迹处理、滤波、不确定性与实验框架|C|环境切分、真实可见信息限制和共同协议|
|经典力学、动力系统、证明与数值误差分析|D|命题成立条件、反例、物理解释与证据界限|

建议先做一个明确限时的可行性试跑，例如各候选题投入2小时后核查门槛。这是管理预算，不是预计2小时能完成建模。记录实际消耗、失败点和剩余工作，再决定是否转题。

人时与运行时暂不报具体预测：没有模块试跑和队员能力证据，给“某题需要多少小时”会制造伪精确。后续可按W=Σ模块实测剩余人时估算工作量；经过并行分工后的日历工期还取决关键路径，不能简单除以三。求解器运行时间也要与人工工作量分开记录。

## 10. 最终选题建议与使用方式

先看门槛，再看团队证据，最后看综合分。默认优先试跑B；若团队已有成熟多场模型则A可上升；若三源数据与共同协议已熟悉则C可上升；D只有在能够独立论证长期分布和守恒兼容时才值得优先。

本报告不按“算法听起来高级”评分，也不把数据量直接换算为难度。其严谨性来自可追溯的需求、明示的价值权重、可复算的算术和不确定性说明。正式选题前应把实际试跑证据补入，而不是把当前分数当客观定论。
