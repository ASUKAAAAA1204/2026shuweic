# 第三问 baseline 的内部种子稳定性对照

**本地审核稿 · 2026 年 11 月 22 日。** 对照对象取自 `v1.0.0-final`（`9f8bc05`）第三问 B 最终方案公开入口的 `Policy("baseline")`。固定任务、真实工期、预算和其他约束后，baseline 的首步在全部已测实例中均一致。终稿 B_K64 的平均加权按时率更高，同一实例跨种子的波动也更大。

## 抽样与配对

baseline 按截止期压力选择调度规则。压力判断对各任务的 64 个等距分位点做随机排列，原种子为 20261123 加任务编号的 CRC32。实验只在运行时替换这个种子常数，保留分位点、任务编号偏移、排序、压力阈值和完工反馈。B_K64 则用 64 个联合场景做调度前瞻，两种策略的随机步骤不同。

两种策略共用同一套重复编号。B_K64 的正式内部种子是 20261122，baseline 的正式种子常数是 20261123。两者均从自身的正式值加上相同偏移，同一重复编号不代表抽到了完全相同的内部场景。每次回放都重新初始化策略和引擎。外部工期种子、逐任务实际工期和实例指纹始终配对。

首批用 3 个官方案例、30 个外部工期种子、5 种工期映射组成 450 个固定实例，每例使用原批的 20 个内部种子，得到 9,000 次新 baseline 回放。复验只取名义与长工期的 180 个原实例，换用与首批互不重叠的 20 个内部种子，得到 3,600 次新回放。B_K64 对照数据沿用既有两批实验。450 个 baseline 原种子实例与冻结归档逐项匹配，数值最大绝对差为 5.69×10⁻¹⁴；全部 12,600 次回放均核对执行工期并从事件独立计分，非法动作数为 0。[回放与归档核验](../results/q3_baseline_seed_control/audit.json)

## 平均按时率与单实例波动

名义工况为 α=1、β=0.5 秒，长工期为 α=1.5、β=0.5 秒。每档 90 个实例，三个案例等权。标准差先在同一实例的 20 次回放中计算（样本标准差），再对实例取平均。首步一致率为同一实例内任取两个不同内部种子时首个动作相同的比例，每例共有 190 对。

| 工况 | 策略 | 平均加权按时率，首批 / 复验批 | 单实例标准差均值，首批 / 复验批（百分点） | 首步一致率，首批 / 复验批 |
|---|---|---:|---:|---:|
| 名义 | baseline | 85.13% / 85.12% | 0.036 / 0.035 | 100% / 100% |
| 名义 | B_K64 | 90.42% / 90.36% | 2.79 / 2.88 | 54.56% / 55.61% |
| 长工期 | baseline | 69.25% / 69.25% | 0 / 0 | 100% / 100% |
| 长工期 | B_K64 | 71.03% / 71.07% | 5.59 / 5.85 | 52.11% / 42.63% |

名义工况中，baseline 两批各有 **1/90** 个实例因内部种子不同而改变按时率，均为 S3、外部种子 2026111714。这一实例的两种结果分别为 84.375% 和 90.625%，首批各出现 10 次，复验批分别出现 11 和 9 次。首步完全一致时，后续决策仍可能分化。长工期下，90 个实例在两批中各自的完整动作序列均保持一致。

复验批中，B_K64 的平均按时率比 baseline 在名义、长工期下分别高 **5.24、1.82 个百分点**。在这批固定任务上，baseline 的动作和得分对换种子更稳定，B_K64 的优势体现为更高的平均按时率。这些结果适用于三个官方案例和本次工期池。[五档工况及两批统计](../results/q3_baseline_seed_control/summary.csv) · [逐次回放与动作指纹](../results/q3_baseline_seed_control/trials.csv.gz)
