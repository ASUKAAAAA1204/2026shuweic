## 从工作区复现

在本分支仓库根目录打开 PowerShell。此次后端对照在 Windows、Python 3.14.5、NumPy 2.4.4、pandas 3.0.3 和项目 SciPy 环境下实测。NumPy 后备内核使用 NumPy 2.x。Windows 的默认模式优先使用 PATH 中的 MinGW g++（本次为 16.1.0），缺少该程序时自动运行 NumPy。其他平台默认选用 NumPy，本次逐项核验在 Windows 完成。第三问使用分支内的任务配置、时长索引和冻结参数，第一、二问的全量重跑仍需恢复相应赛事附件和预处理数组。图件复现另需 PyMuPDF 与微软雅黑字体。

1. 在独立目录重跑第三问，并和分支中的 C++ 基准对照。

   ```powershell
   python -B -X utf8 "C题工作区/正式方案/code/run_all.py" --q3-only --output tmp/roadmap_formal_reproduction
   python -B -X utf8 "C题工作区/正式方案/code/verify_backend_parity.py" tmp/roadmap_formal_reproduction
   ```

   日志中的 `Q3 nominal numerical backend` 和输出的 `q3/formal_release/backend.json` 给出实际后端。`--q3-only` 使用 Q1、Q2 的冻结存档，实际重跑 Q3 的名义调度和非名义映射。图中两项指标取 30 个官方种子、三个案例等权的四级结果。

   如要在装有 g++ 的机器上专门复核后备路径，可在同一 PowerShell 执行 `$env:SHUWEICUP_Q3_BACKEND = "numpy"`，随后运行上述命令。把该值设回 `auto` 即恢复自动选择。分别生成两个目录后可直接比对，例如 `python -B -X utf8 "C题工作区/正式方案/code/verify_backend_parity.py" tmp/q3_numpy --reference tmp/q3_cpp`。

   验收时使用两个独立的空 DLL 缓存目录，其中一次从 PATH 移除 g++，以自动模式完成运行，结束时其缓存目录仍无 DLL。两次按“种子组、工况、种子、版本”配对 12,468 条记录（30 个官方种子和 2,048 个晋级种子，各三工况、两版）。每条记录的完整动作、来源及反馈事件摘要一致，合计 151,401 个事件。S1、S2 跨版本逐种子一致。同批官方二级对照另有 90 条。原调度包的 5 种映射、2 种方法合计 900 条，其中非名义映射 720 条。全部评分字段实测最大差为 0，非法动作数为 0。校验器容差为 1e−9，轨迹摘要逐条精确比对，机器实际耗时另计。[核验记录](../C题工作区/正式方案/results/q3/backend_parity.json)

2. 从 Git 取出提交版的求解代码、参数和任务配置，在临时目录重跑。脚本检查新旧任务配置和验证来源池顺序，按“案例、种子”配对，并核对两版各自的存档分数。

   ```powershell
   python -B -X utf8 code/reproduce_roadmap_comparison.py --replay tmp/roadmap_formal_reproduction --output results/roadmap_c6a63a5_vs_current
   ```

   提交版原程序回放 3 个案例 × 30 个种子 × 5 个映射 × 2 种方法，共 900 条。取其中 90 条名义映射的正式方法，与当前版配对。两端四项指标均与各自存档在绝对容差 1e−9 内一致。查看 `official_30.csv` 的 `overall` 行可得到图中精确数值。

3. 复现图件。在可编辑 DrawIO 中，第三问的结果框使用上表整体行，按时率、完成率和差值显示到小数点后两位。在现有单页矢量底图上依照 XML 重排指定文字，可用以下命令导出到独立目录。

   ```powershell
   python -B -X utf8 code/export_roadmap_q3.py --output tmp/roadmap_formal_reproduction/export_check
   Get-FileHash figures/fig_roadmap.png,tmp/roadmap_formal_reproduction/export_check/fig_roadmap.png
   ```

   复核得到单页 1180 × 805 pt 矢量 PDF，PNG 为 1770 × 1208 像素。两份 PNG 的 SHA-256 均为 `b01af0cf7747522c2aaf00427082fa758a5561d0aa8c7d5e18589ccc3703ab74`。XML 比较记录到 7 个已有文字单元更新、1 个结果行新增，其他节点与连线一致。导出器检查文字宽度、PDF 文本和局部修改边界，原图与交付图在指定区域外的像素差异为 0。[DrawIO 源图](../figures/fig_roadmap.drawio) · [矢量 PDF](../figures/fig_roadmap.pdf) · [PNG](../figures/fig_roadmap.png)
