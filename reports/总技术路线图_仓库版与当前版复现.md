## 从工作区复现

在本分支的仓库根目录 打开 PowerShell。实测环境为 Python 3.14.5、NumPy 2.4.4、pandas 3.0.3、MinGW g++ 16.1.0；沿用项目的 SciPy。制图使用 PyMuPDF 1.28.0 和 Windows 微软雅黑常规、粗体字体。需要保留本仓库的 Git 历史、当前正式调度代码与冻结参数、工作区赛事附件，以及预处理后的私有时长索引。

1. 从当前正式入口重跑第三问，输出到独立目录。

   ```powershell
   python -B -X utf8 "C题工作区/正式方案/code/run_all.py" --q3-only --output tmp/roadmap_formal_reproduction
   ```

   该入口也执行原 2,048 种子晋级组的回归核验。本图和下列版本比较均只取 `split=official` 的 30 个种子。实测核验通过 12,468 条三级、四级记录，非法动作数为 0。新生成的 `official_versions.csv` 与正式目录同名文件的 SHA-256 完全相同，为 `1c6b70787a344c545ce36d5d9005c3ab6af62d33617b1fc074b254bce1522561`。

2. 从 Git 取出提交版的求解代码、参数和任务配置，在临时目录重跑。脚本检查新旧任务配置和验证来源池顺序，按“案例、种子”配对，并核对两版各自的存档分数。

   ```powershell
   python -B -X utf8 code/reproduce_roadmap_comparison.py --replay tmp/roadmap_formal_reproduction --output results/roadmap_c6a63a5_vs_current
   ```

   提交版原程序回放 3 个案例 × 30 个种子 × 5 个映射 × 2 种方法，共 900 条。取其中 90 条名义映射的正式方法，与当前版配对。两端四项指标均与各自存档在绝对容差 1e−9 内一致。查看 `official_30.csv` 的 `overall` 行可得到图中精确数值。

3. 复现图件。在可编辑 DrawIO 中，第三问的结果框使用上表整体行，按时率、完成率和差值显示到小数点后两位。在现有单页矢量底图上依照 XML 重排指定文字，可用以下命令导出到独立目录。

   ```powershell
   python -B -X utf8 code/export_roadmap_q3.py --output tmp/roadmap_formal_reproduction/export_check
   Get-FileHash figures/fig_roadmap.png,tmp/roadmap_formal_reproduction/export_check/fig_roadmap.png
   ```

   复核得到单页 1180 × 805 pt 矢量 PDF，PNG 为 1770 × 1208 像素。两份 PNG 的 SHA-256 均为 `b01af0cf7747522c2aaf00427082fa758a5561d0aa8c7d5e18589ccc3703ab74`。XML 比较记录到 7 个已有文字单元更新、1 个结果行新增，其他节点与连线一致。导出器检查文字宽度、PDF 文本和局部修改边界，原图与交付图在指定区域外的像素差异为 0。[DrawIO 源图](../figures/fig_roadmap.drawio) · [矢量 PDF](../figures/fig_roadmap.pdf) · [PNG](../figures/fig_roadmap.png)
